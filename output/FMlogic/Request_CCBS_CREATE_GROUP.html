Request_CCBS_CREATE_GROUP

CCBS User Group Creation — parameter-driven with TrueLife ID as group name
Backend: CCBS Author: DESKTOP-995HR2V Priority: 5 Pattern: FIRE-AND-FORGET Response: GROUP_ID write-back
§1 — Overview & Purpose
CCBS_CREATE_GROUP creates a user group in CCBS for the order's account. Group attributes (type, description, identifier) come from ProcessConfig Parameter values. The group name is derived from ExtInfo[TRUELIFE_ID].Value (written by FM28 response) with a hardcoded "TF_" prefix.
Mandatory parameters: If the activity has no Parameter entries (Parameter@length == 0), the rule throws "DATA_ISSUE" immediately. Parameters GROUP_TYPE, GROUP_DESC, GROUP_IDENTIFY are required.
Fire-and-forget: Uses Event.Ext.sendEventImmediate + manual RequestCount++. Fan-in: count("000") == RequestCount.
Response write-back: OrderData.ExtendedInfo[Name="GROUP_ID"] ← createGroupRes.userGroupIdInfo.GroupId. Consumed by downstream group member additions.
