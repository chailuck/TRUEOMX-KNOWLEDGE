SBM FUP — doService (function_id=104300015) — Update OU Billing Cycle

Priority: 5 forwardChain: true Backend: SBM Event: SBM_FUP_DO_SERVICE Loop: ParentOU + ChildOU Generated: 2026-09-23
§1 — Overview & Purpose

Invokes SBM FUP doService (function_id 104300015) to update billing cycle information for each OU. Loops over all ParentOU entries and their nested ChildOU entries populated by the preceding INTX_GET_SPECIAL_OFFER_IND_BY_CUST step. Sends one request per OU (ParentOU or ChildOU), with the OU's RefId as the correlation key.

💡 Note: The JMS event type dispatched is SBM_FUP_DO_SERVICE — the rule name uses the logical alias SBM_FUP_UPDATE_OU_INFO. The function_id=104300015 is hardcoded.

Parameters sent per OU: fupID = OUId, bc = BillCycleNo from Customer.

§5 — Execution Flow
  1. Check resubmit; if so: PurgePendingRequestsBeforeResubmit
  2. Outer loop: iterate over Customer.ParentOU[p]
  3. For each ParentOU: check if already succeeded (response array scan); evaluate PreExecCheck using GetXMLForOU
  4. If pass: send SBM_FUP_DO_SERVICE with pOuRefId and pOuId
  5. Inner loop: iterate over ParentOU[p].ChildOU[c]
  6. For each ChildOU: same success check, GetXMLForChildOU, send request with cOuRefId and cOuId
  7. Set WAITING_RESPONSE; persist to DB
