Request_SBM_FUP_CHANGE_MEMBER

Adds or removes Subscribers from FUP groups in SBM — subscriber-level iteration with dual function_id dispatch
System: SBM Priority: 5 Author: DESKTOP-995HR2V function_id: 104300004 (ADD) / 104300005 (REMOVE) Pattern: Subscriber-loop POU/COU + direct send Fan-in: count(success) == RequestCount Generated: 2026-09-15
Key difference from SBM_FUP_CREATE_GROUP / DELETE_GROUP: This FM iterates over Subscribers within each OU (not just OUs). Sends one SBM request per subscriber. function_id is determined by Parameter[0] ("ADD"=104300004 / "REMOVE"=104300005). Payload has 3 parameters: fupID, msisdn, and optional socCapmax (only on ADD when subscriber has FCA special offer).
§1 Overview & Purpose

Adds or removes individual Subscribers from FUP (Fair Usage Policy) groups in SBM. For each Subscriber under each eligible OU, sends a SBM_FUP_DO_SERVICE request with either function_id=104300004 (ADD) or 104300005 (REMOVE) depending on Parameter[0].

On ADD, includes an optional socCapmax parameter taken from the subscriber's FCA-type special offer indicator offer name.

§5 Execution Flow Diagram
1
Init — If resubmit, PurgePendingRequestsBeforeResubmit. Get param = Parameter[0]. Validate: throw DATA_ISSUE if param is not "ADD" or "REMOVE".
2
POU loop — OU-level PreExecCheck via GetXMLForOU → chkRes_OU.
3
POU Subscriber loop — For each sub: CompletionStatus==2 check (by sub.RefId). If not complete: Subscriber-level PreExecCheck via GetXMLForSubscriber. Send if chkRes_OU==true OR chkRes==true.
4
Send (per subscriber) — Build SBM_FUP_DO_SERVICE with function_id from param, fupID=pOuId, msisdn, optional socCapmax. sendEventImmediate. RequestCount++. isSkipped=false. Send audit logger (always, even on resubmit).
5
COU loop — Same structure: OU-level PreExecCheck (GetXMLForChildOU), then Subscriber loop with GetXMLForSubscriberInChildOU. fupID=cOuId.
6
Post-loop — If !isSkipped → Status="1" + SendDataToDB. Else → SkipActivity("4").
7
Exception → HandleActivityException.
Dual-condition gate: Send fires if String.equals(chkRes,"true") || String.equals(chkRes_OU, "true") — either the OU-level OR the subscriber-level PreExecCheck passes (OR logic, not AND).
⚠ Audit logger on resubmit: Event.Ext.sendEventImmediate(Logger) is sent OUTSIDE the if(!isActResub) block — it fires on every request send, including resubmit. RequestCount++ is gated but audit is not.

§18 Full Source Code
/**
 * @author DESKTOP-995HR2V
 */
rule Rules.OMConsumers.OMXFM.Request.Request_SBM_FUP_CHANGE_MEMBER {
    attribute { priority = 5; forwardChain = true; }
    when { ... ActivityID == "SBM_FUP_CHANGE_MEMBER" ... }
    then {
        boolean isActResub = (orderCurrentActivity.RequestCount>0 && orderRequest.IsOrderResubmitted);
        try {
            if(isActResub) PurgePendingRequestsBeforeResubmit(...);
            String param = nextAct.Parameter[0]; // "ADD" or "REMOVE"
            if(!String.equals(param,"ADD") && !String.equals(param,"REMOVE"))
                throw Exception.newException("DATA_ISSUE", "Param is missing.", null);

            for(int p=0; p<pOuLen; p++) {
                // OU-level PreExecCheck → chkRes_OU
                for(int s=0; s<pSubLen; s++) {
                    sub = ParentOU[p].Subscriber[s];
                    // CompletionStatus==2 check using sub.RefId
                    if(!reqSuccess) {
                        // Subscriber-level PreExecCheck → chkRes
                        if(chkRes=="true" || chkRes_OU=="true") {
                            reqEvent = Event.createEvent("xslt://...");
                            /* §9.8 Variant ①: params orderRequest, refId, param, pOuId, msisdn, sub
                               ns:function_id from xsl:choose on param (104300004/104300005)
                               params: fupID=pOuId, msisdn, optional socCapmax if ADD+FCA */
                            Event.Ext.sendEventImmediate(reqEvent);
                            if(!isActResub) orderCurrentActivity.RequestCount++;
                            isSkipped = false;
                            Event.Ext.sendEventImmediate(Logger); // always, even on resubmit
                        }
                    }
                }
                // COU subscriber loop — GetXMLForChildOU, GetXMLForSubscriberInChildOU
            }
            if(!isSkipped) { Status="1"; SendDataToDB(); }
            else SkipActivity("4");
        } catch(Exception ae) { HandleActivityException(...); }
    }
}
