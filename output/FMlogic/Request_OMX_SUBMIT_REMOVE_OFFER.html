Request_OMX_SUBMIT_REMOVE_OFFER

Submits a child remove-offer order to the OMX SubmitOrder service per subscriber, targeting IR offers (REMOVE_PACK). ORDER_TYPE and SERVICE_TYPE driven by activity parameters.
Backend: OMX SubmitOrder (Child Order — IR Remove) Fan-out: POU + COU subscribers Event: OMX_CREATE_CHILD_ORDER Author: DESKTOP-995HR2V Lines: 135 Step: 84 forwardChain: true
§1 — Overview & Purpose

Submits a child order to the OMX SubmitOrder service to remove IR (International Roaming) offers per subscriber. Uses the same OMX_CREATE_CHILD_ORDER event and fan-out structure as OMX_SUBMIT_POSTPAID_ADD_BENEFIT, but targets FE offers with a non-empty REMOVE_PACK ExtendedInfo key, and takes two activity parameters: ORDER_TYPE and SERVICE_TYPE. Contains multiple copy-paste logger bugs where OPERATION_NAME is wrong.

§5 — Execution Flow
1
Init: isActResub = (RequestCount > 0 && IsOrderResubmitted). Read order_type (ORDER_TYPE) and service_type (SERVICE_TYPE). isSkipped = true. childIndex = 0.
2
POU subscriber loop (POU p → Sub ps): childIndex++ (before resub guard). Resub guard. PreExecCheck. Send OMX_CREATE_CHILD_ORDER with orderId = concat("IR_", OrderID). RequestCount++ if !isActResub. Logger (wrong OPERATION_NAME). isSkipped = false.
3
COU subscriber loop (POU p → COU c → Sub cs): same — childIndex++ first. PreExecCheck = GetXMLForSubscriberInChildOU. Same orderId = concat("IR_", OrderID). Logger (same wrong OPERATION_NAME).
4
Completion: if (!isSkipped) → Status = GetActivityStatusString("1", false); SendDataToDB. Else → SkipActivity("4").
5
Exception: catch(Exception ae) → HandleActivityException(orderRequest, orderCurrentActivity, ae, "")

9.2 orderId — Non-Unique Bug

ns:orderId = concat("IR_", OrderID)

This is IDENTICAL for all subscribers. Example: three subscribers all get IR_ORD-123. childIndex is computed (0→1→2→…) but is unused in the orderId construction.
