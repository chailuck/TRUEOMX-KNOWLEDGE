Request_ICC_TVS_SUBMIT_ORDER

TIBCO BusinessEvents FM — ICC TVS Submit Order (trueID TV, 3 variants in FULL_SUSPEND)
Rule: Rules.OMConsumers.OMXFM.Request.Request_ICC_TVS_SUBMIT_ORDER Priority: 5 forwardChain: true No author Backend: ICC (trueID TV service) Generated: 2026-09-16
§1 — Overview & Purpose

Fires when ActivityID == "ICC_TVS_SUBMIT_ORDER". Dual-loop per subscriber. Submits an order to the ICC trueID TV service (TvsSubmitOrderReq) for suspension of TV-related subscriptions. This FM appears three times in FULL_SUSPEND with different REASON parameter values and different PreExecCheck gates.


Step InstanceREASONACTION_CODEPreExecCheck gate
ICC_TVS_SUBMIT_ORDER_CVG (step 31)TFULLSTVS_NO present
ICC_TVS_SUBMIT_ORDER_BY_REQ (step 32)TDISCOTTSChannel!="CCBS" and trueIDTV ParameterInfo non-empty
ICC_TVS_SUBMIT_ORDER_BY_COLLECTION (step 33)TFULLOTTSChannel="CCBS" and trueIDTV ParameterInfo non-empty

tvs_customer_id logic: When REASON=TFULL AND subscriber has TVS_NO ExtendedInfo → use TVS_NO value; otherwise use "0". TVS_NO is written by the preceding ATS_ENQUIRY_CAMPAIGN_CVG step.

Required parameters: ORDER_TYPE, ACTION_CODE, REASON — throws DATA_ISSUE if any missing.

§5 — Execution Flow
  1. Load ORDER_TYPE, ACTION_CODE, REASON from parameters → throw DATA_ISSUE if null
  2. Load SubmissionDate (DateTime.now())
  3. Dual-loop: POU + COU subscribers
  4.   Apply PreExecCheck per subscriber (varies by step instance)
  5.   Resolve tvsCustomerId: if REASON="TFULL" and TVS_NO ExtendedInfo present → TVS_NO, else "0"
  6.   Build ICC_TVS_SUBMIT_ORDER event with TvsSubmitOrderReq
  7.   ActionRequestEvent; increment RequestCount; send audit log
  8. On any dispatch → status "1"; DB persist
  9. On all skip → SkipActivity("4")

§19 — Response Message Rule
