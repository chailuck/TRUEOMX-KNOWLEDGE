OMX_OFFER_INCLUSION

FM Logic Documentation — Internal Mandatory Related Offer Injection (No Backend Call — Uses CCBS_GOD Response, Populates RelatedOffersArray with SelectedByDefault='Y' Offers)
Rule: Rules.OMConsumers.OMXOM.OMX_OfferInclusion ActivityID: OMX_OFFER_INCLUSION Priority: 5 Pattern: Internal Computation (OMXOM) — No External Call Completion: NextActivity or SkipActivity("4") Generated: 2026-09-11
§1 — Overview & Purpose

OMX_OFFER_INCLUSION is an internal OMXOM computation rule that auto-injects mandatory related offers into each order offer's RelatedOffersArray. It reads the GetOfferDetails (CCBS_GOD) response already in working memory, finds all RelatedOffer entries where SelectedByDefault == 89 (ASCII 'Y'), and ensures each one is present in the corresponding order offer. If absent, it creates a new RelatedOffersArray concept and appends it.

No backend call is made. It uses the CCBS_GOD response data already stored as GetOfferDetailsRes concepts in working memory. On completion it calls NextActivity (or SkipActivity if PreExecCheck fails).

Key design notes:
  • Prerequisite: CCBS_GOD response in memory. Collects all Activity entries where ActivityID=="CCBS_GOD" into a list; throws DATA_ISSUE if none found.
  • SelectedByDefault=89 ('Y') gate. The original RelationType==77 logic was commented out ("Change in logic by TRUE"). Now uses SelectedByDefault field instead.
  • FE_OR_CCBS activity parameter filter. Activity parameter FE_OR_CCBS restricts which offers to process. If parameter is null → process all offers (no filter).
  • PreExecCheck gate. Full order XML serialized via Instance.serializeUsingDefaults(orderRequest), then XPath evaluated. If not "true" → SkipActivity("4") (not NextActivity).
  • Idempotent add: skip if already present. Checks if manSoc is already in offer's RelatedOffersArray before adding — no duplicates.
  • CUG_ID ParameterInfo: Subscriber Offer variants include a ParameterInfo[ParamName=CUG_ID] if CUG_IND=Y in the related offer's SocProperties. Agreement Offer variants do not include CUG_ID.
  • Audit Logger: conditional on AllowWriteLog(OrderType). Unlike OMX_CAL_OFFERS_EFF_DATE, logging here is gated by the order type permission flag.
  • Multiple CCBS_GOD acts: Iterates over ALL collected CCBS_GOD activity entries (may be more than one).

§5 — Execution Flow Diagram
  1. Serialize order: Instance.serializeUsingDefaults(orderRequest) → full XML string for PreExecCheck XPath evaluation.
  2. PreExecCheck gate: If String.length(PreExecCheck) > 0 → evaluate XPath against sXML. If result != "true" → SkipActivity("4") and stop.
  3. Read activity parameters: GetActivityParamValueFromKey(orderCurrentActivity, "FE_OR_CCBS") → filter string (may be null).
  4. CCBS_GOD prerequisite check: Collect all ProcessFlow.Activities where ActivityID=="CCBS_GOD" into list. Throw DATA_ISSUE if empty.
  5. Triple-nested loop: For each GOD activity → for each GOD response offer (godSoc) → for each RelatedOffer where SelectedByDefault==89 → extract manSoc, manOffNm, manSrvTyp, CUG_IND from SocProperties.
  6. PP@POU: For each ParentOU Agreement Offer matching godSoc AND FE_OR_CCBS filter → check if manSoc in RelatedOffersArray → if not, create RelatedOffersArray concept (Agreement variant, no CUG_ID) and append.
  7. Sub@POU: For each ParentOU Subscriber SubscriberOffer matching godSoc AND FE_OR_CCBS filter → same check/add pattern (Subscriber variant, with CUG_ID if CUG_IND=Y).
  8. PP@COU: For each ChildOU Agreement Offer matching godSoc AND FE_OR_CCBS filter → same as PP@POU (Agreement variant, no CUG_ID).
  9. Sub@COU: For each ChildOU Subscriber SubscriberOffer matching godSoc AND FE_OR_CCBS filter → same as Sub@POU (Subscriber variant, with CUG_ID, but ValuesArray conditional on CUG_ID having a value).
  10. Complete: NextActivity(orderRequest, orderCurrentActivity); conditionally send Logger audit event if AllowWriteLog(OrderType).
§6 — Rule Action (THEN) — Annotated Logic
// Serialize full order for PreExecCheck
String sXML = Instance.serializeUsingDefaults(orderRequest);
Object arrLstGODs = Collections.List.createArrayList();
if(String.length(PreExecCheck)>0)
    chkRes = XPath.execute("/("+chkXPath+")", sXML, "ns0=www.tibco.com/...");

if(String.equals(chkRes,"true")) {
    String fe_or_ccbs = Helpers.GetActivityParamValueFromKey(orderCurrentActivity, "FE_OR_CCBS");
    int selByDefInd = 89;  // ASCII 'Y'

    // Collect all CCBS_GOD activities
    for(int iActItr; iActItr < Activities@length; iActItr++)
        if(ActivityID=="CCBS_GOD") Collections.add(arrLstGODs, act);
    if(Collections.size(arrLstGODs)==0) throw Exception("DATA_ISSUE", "OMX did not find Get Offer Details response.");

    for(int iGOD; iGOD < arrGODs@length; iGOD++) {              // each GOD act
        for(int iGODResOff; iGODResOff < godAct.Response@length; iGODResOff++) { // each GOD offer
            godSoc = godRes.Code; iRelOff = godRes.RelatedOffers@length;
            for(int iRelOff; iRelOff < iRelOff; iRelOff++) {    // each related offer
                if(godRes.RelatedOffers[i].SelectedByDefault == 89) {  // SelectedByDefault='Y'
                    manSoc = Code; manOffNm = Name; manSrvTyp = OfferType;
                    socProperties = SocProperties; cugInd = extract(CUG_IND= ...);

                    for(iPOU...) {
                        // PP@POU: Agreement Offers
                        if(fe_or_ccbs==null || FE_OR_CCBS_match) {
                            if(agOff.Soc == godSoc) {
                                isThere = scan RelatedOffersArray for manSoc;
                                if(!isThere) agOff.RelatedOffersArray += Instance.createInstance(
                                    "xslt://RelatedOffersArray (Agreement variant)");
                            }
                        }
                        // Sub@POU: Subscriber Offers (same pattern + CUG_ID)
                        if(fe_or_ccbs==null || FE_OR_CCBS_match) {
                            if(subOff.Soc == godSoc) {
                                isThere = scan RelatedOffersArray for manSoc;
                                if(!isThere) subOff.RelatedOffersArray += Instance.createInstance(
                                    "xslt://RelatedOffersArray (Subscriber variant + CUG_ID)");
                            }
                        }
                        // PP@COU: ChildOU Agreement Offers (same as PP@POU)
                        // Sub@COU: ChildOU Subscriber Offers (same as Sub@POU, ValuesArray conditional)
                    }
                } // SelectedByDefault='Y'
            }
        }
    }
    Helpers.NextActivity(orderRequest, orderCurrentActivity);
    if(Helpers.AllowWriteLog(OrderType)) { /* Logger audit */ }
} else {
    Helpers.SkipActivity(orderRequest, orderCurrentActivity, "4");
}
§7 — FE_OR_CCBS Filter & SelectedByDefault Logic

§7.1 — FE_OR_CCBS Activity Parameter Filter

FE_OR_CCBS valueEffect
null (parameter absent)No filter — ALL offers processed regardless of their FE_OR_CCBS tag
"FE"Only offer objects where ExtendedInfo[Name='FE_OR_CCBS']/Value == "FE" are processed

The FE_OR_CCBS filter is applied on EACH individual offer object using an inline XPath expression bound to the currOffer concept variable.

For each related offer, CUG_IND is extracted from SocProperties via String.substringBefore(String.substringAfter(socProperties, "CUG_IND="), ";").

§9 — Concept Construction — RelatedOffersArray Variants

§9.1 — Agreement Offer Variant (PP@POU and PP@COU)

Used for both ParentOU and ChildOU Agreement Offers. Same XSLT. No CUG_ID ParameterInfo.
  • createObject
    • object @extId←$manSocExt (OMXUtils.generateTrackingID()) Always
      • OfferName←$manOffNm (godRes.RelatedOffers[i].Name) Always
      • ServiceType←$manSrvTyp (godRes.RelatedOffers[i].OfferType) Always
      • Soc←$manSoc (godRes.RelatedOffers[i].Code) Conditional: $manSoc
      • RcIndicator←$godRes/RelatedOffers[n]/RcIndicator Always
      • SocProperties←$socProperties Always

§9.2 — Subscriber Offer Variant POU (Sub@POU)

Used for ParentOU SubscriberOffers. OfferName/ServiceType/Soc are conditional. CUG_ID ParameterInfo has unconditional ValuesArray.
  • createObject
    • object @extId←$manSocExt Always
      • OfferName←$manOffNm Conditional: $manOffNm
      • ServiceType←$manSrvTyp Conditional: $manSrvTyp
      • Soc←$manSoc Conditional: $manSoc
      • ParameterInfo Conditional: $cugInd='Y'
        • ParamName←"CUG_ID" Always (when parent present)
        • ValuesArray←$subOff/ExtendedInfo[Name="CUG_ID"]/Value Always (when parent present)
      • RcIndicator←$godRes/RelatedOffers[n]/RcIndicator Always
      • SocProperties←$socProperties Always

§9.3 — Subscriber Offer Variant COU (Sub@COU)

Same as Sub@POU but ValuesArray for CUG_ID is also conditional on the ExtendedInfo value existing.

Difference vs Sub@POU: <ValuesArray> inside ParameterInfo is wrapped in <xsl:if test="$subOff/ExtendedInfo[Name='CUG_ID']/Value">. This handles COU subscribers that may not have a CUG_ID ExtendedInfo set yet.

§17 — Migration Notes & Recommendations

Functional Requirements

RefRequirement
R1Evaluate PreExecCheck against full serialized order XML (serializeUsingDefaults). If false → SkipActivity("4"), no injection.
R2Read FE_OR_CCBS activity parameter. If null → no filter (process all offers). If set → only process offers where ExtendedInfo[FE_OR_CCBS] matches.
R3Require CCBS_GOD in ProcessFlow.Activities. Throw DATA_ISSUE if none found.
R4For each GOD response offer, for each RelatedOffer with SelectedByDefault==89: check and inject if absent. Do NOT inject duplicates.
R5Process all 4 scopes: PP@POU, Sub@POU, PP@COU, Sub@COU — same pattern per scope.
R6Agreement variant: OfferName/ServiceType always; Soc conditional. No CUG_ID ParameterInfo.
R7Subscriber variant: OfferName/ServiceType/Soc all conditional. CUG_ID ParameterInfo if CUG_IND=Y in SocProperties. COU variant also gates ValuesArray on value existence.
R8Audit log conditional on AllowWriteLog(OrderType) — not unconditional.

rule Rules.OMConsumers.OMXOM.OMX_OfferInclusion {
    attribute { priority = 5; forwardChain = true; }
    declare { OrderRequest orderRequest; Activity orderCurrentActivity; }
    when { /* extId / ActivityID=="OMX_OFFER_INCLUSION" / NextActivityID / Status=="WAITING" */ }
    then {
        try {
            sXML = Instance.serializeUsingDefaults(orderRequest);
            chkRes = XPath.execute(...); // if PreExecCheck present
            if(chkRes == "true") {
                fe_or_ccbs = GetActivityParamValueFromKey("FE_OR_CCBS");
                selByDefInd = 89; // ASCII 'Y'
                // Collect all CCBS_GOD acts; throw DATA_ISSUE if none
                for(iGOD...) {
                    for(iRes...) {  godSoc = godRes.Code;
                        for(iRelOff...) {
                            if(SelectedByDefault == 89) {
                                manSoc = Code; manOffNm = Name; manSrvTyp = OfferType;
                                cugInd = extract CUG_IND from SocProperties;
                                for(iPOU...) {
                                    // PP@POU: find agOff.Soc==godSoc + FE_OR_CCBS match → add if !isThere
                                    //   Instance.createInstance(xslt://RelatedOffersArray [Agreement])  — see §9.1
                                    // Sub@POU: same + CUG_ID ParameterInfo → add if !isThere
                                    //   Instance.createInstance(xslt://RelatedOffersArray [Sub POU])    — see §9.2
                                    // PP@COU: same as PP@POU for ChildOU Agreement Offers             — see §9.1
                                    // Sub@COU: same as Sub@POU, ValuesArray conditional               — see §9.3
                                }
                            }
                        }
                    }
                }
                Helpers.NextActivity(orderRequest, orderCurrentActivity);
                if(AllowWriteLog(OrderType)) { /* Logger audit — OPERATION_NAME: /Rules/.../OMX_OfferInclusion */ }
            } else {
                Helpers.SkipActivity(orderRequest, orderCurrentActivity, "4");
            }
        } catch(Exception ae) { HandleActivityException; }
    }
}
