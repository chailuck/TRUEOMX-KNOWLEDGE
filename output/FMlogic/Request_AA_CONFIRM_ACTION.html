Request_AA_CONFIRM_ACTION

Confirms the AA action for each subscriber by sending MSISDN and SrvTrxNo to the AA system. Also copies RequestCount to the AA_CHECK_CONFIRMATION activity.
Activity: AA_CONFIRM_ACTION Backend: AA Pattern: Fire-and-Forget (RequestCount++) Scope: Subscriber (ParentOU + ChildOU) Generated: 2026-09-23
§1 — Overview & Purpose

Sends an AAConfirmAction message to the AA system for each subscriber, providing the subscriber's MSISDN and transaction number (SrvTrxNo). After the loop, it copies its own RequestCount to the AA_CHECK_CONFIRMATION activity so that the subsequent confirmation check knows how many responses to expect.

[BUG] The audit logger's OPERATION_NAME is hardcoded as "CCBS_CANCEL_SUBS" — a copy-paste error from a different rule. Functionally does not affect execution but misleads audit trails.

§5 — Execution Flow
  1. Iterate ParentOU[i].Subscriber[j]
  2. Check if already successfully responded (skip if yes)
  3. Evaluate PreExecCheck (if set) via GetXMLForSubscriber
  4. If passes: build and send AA_CONFIRM_ACTION event (sendEventImmediate)
  5. Fire audit logger (LOG_LEVEL=ERROR — note: unusual, likely copy-paste error)
  6. If not resubmit: RequestCount++
  7. Repeat for ChildOU[m].Subscriber[n]
  8. After loop: find AA_CHECK_CONFIRMATION activity, set its RequestCount = currentActivity.RequestCount
  9. If not skipped: set status IN_PROGRESS; else: SkipActivity("4")
