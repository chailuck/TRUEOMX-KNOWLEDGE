Request_CCBS_REMOVE_OFFER_SUBSCRIBER_POST

Backend: CCBS (UpdateSubscriber) Pattern: IntraActivitySequencing Author: RS33-BANDIT Generated: 2026-09-23
§1 — Overview & Purpose

Removes offers from source subscribers via CCBS's UpdateSubscriberRequest event (same event type as CCBS_UPDATE_SUBSCRIBER). Pre-processes all subscribers to build global SOC pooling arrays (alSOCs, alPropVal, alInstVal), then for each subscriber builds a filtered set of offers to remove based on FE_OR_CCBS ExtendedInfo and PreExecCheck. Used in MOVE_SUBSCRIBER_NO_PROVISIONING (step 32) to remove existing offers from the source account before the subscriber moves to the target.

Dead Code: logicalDateRes is loaded from working memory and logicalDateVal is assigned, but neither is passed to the XSLT transformer. This is dead code — do not replicate in migration.
Dead Code: ChargeDistributionDetailsInfo block in XSLT uses condition 1=0 — permanently false, never executed.

§5 — Execution Flow
  1. Purge pending requests if resubmit
  2. Load global pooling vars: sPooling (PoolingIndicator), sPrefix (PooledPrefix)
  3. Load logicalDateRes from working memory — DEAD CODE (value not used)
  4. Pre-build SOC arrays for all subscribers (excl. ServiceType=80): alSOCs, alPropVal (poolingIndicator), alInstVal (poolingInstIndicator)
  5. Iterate POU[i] → Subscriber[j]; evaluate PreExecCheck; check reqSuccess guard
  6. Build subOffers list: filter offers by FE_OR_CCBS ExtendedInfo + PreExecCheck
  7. If subOffers empty → skip subscriber; else build and assert UpdateSubscriberRequest event
  8. IntraActivitySequencing.ActionRequestEvent(reqEvent, currActivity)
  9. Repeat for ChildOU subscribers (ChildOU variant has additional ParameterInfo from RelatedOffersArray)
  10. IntraActivitySequencing.SendFirstRequestEvent → IN_PROGRESS
