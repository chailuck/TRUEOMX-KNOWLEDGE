OMX_UPDATE_FE_OR_CCBS_VALUE

Internal OMX Rule — Updates FE_OR_CCBS ExtendedInfo value on all Offers and SubscriberOffers
Namespace: OMXOM (Internal) Priority: 5 Pattern: IN-MEMORY UPDATE (no backend) Author: DESKTOP-995HR2V No response rulefunction
§1 — Overview & Purpose
OMX_UPDATE_FE_OR_CCBS_VALUE is an internal OMX rule (OMXOM namespace) that overwrites the FE_OR_CCBS ExtendedInfo value on every matching Offer and SubscriberOffer in the order. The new value comes from Parameter[0] in the ProcessConfig Activity. No backend call is made; the rule directly mutates in-memory working memory.
Mandatory parameter guard: Parameter@length == 0 throws DATA_ISSUE immediately before any processing. The ProcessConfig Activity must supply at least one Parameter.
Four iteration scopes: ParentOU Agreement Offers, ParentOU Subscriber SubscriberOffers, ChildOU Agreement Offers, and ChildOU Subscriber SubscriberOffers — all are processed in one execution pass.
PreExecCheck scoped helpers: Uses four specialized scoped XML helpers (GetXMLForAgreementOfferFilterWithExtendedInfo, GetXMLForSubscriberOfferFilterWithExtendedInfo, and their ChildOU variants) to evaluate the PreExecCheck XPath against the FE_OR_CCBS filter value for each offer.
Calls NextActivity directly (like FM24/FM27 OMXOM pattern) — no response rulefunction, no RequestCount, no fan-in wait.

§10 — In-Memory Update Mapping
For each POU[p]:
  → Agreement.Offers[o] (if Agreement != null):
      filter = XPath(pagof/ExtendedInfo[Name="FE_OR_CCBS"]/Value)
      scoped XML = GetXMLForAgreementOfferFilterWithExtendedInfo(orderRequest, pAgRefId, pagof.Soc, filter)
      if PreExecCheck passes:
          pagof.ExtendedInfo[i where Name=="FE_OR_CCBS"].Value = param  ← write-back

  → Subscriber[ps].SubscriberOffers[o]:
      filter = XPath(psof/ExtendedInfo[Name="FE_OR_CCBS"]/Value)
      scoped XML = GetXMLForSubscriberOfferFilterWithExtendedInfo(orderRequest, pSubRefId, psof.Soc, filter)
      if PreExecCheck passes:
          psof.ExtendedInfo[i where Name=="FE_OR_CCBS"].Value = param  ← write-back

  → ChildOU[c]:
      → Agreement.Offers[o] (if Agreement != null):
          filter = XPath(cagof/ExtendedInfo[Name="FE_OR_CCBS"]/Value)
          scoped XML = GetXMLForAgreementOfferInChildOUFilterWithExtendedInfo(orderRequest, cAgRefId, cagof.Soc, pOuRefId, filter)
          if PreExecCheck passes:
              cagof.ExtendedInfo[i where Name=="FE_OR_CCBS"].Value = param  ← write-back

      → Subscriber[cs].SubscriberOffers[o]:
          filter = XPath(csof/ExtendedInfo[Name="FE_OR_CCBS"]/Value)
          scoped XML = GetXMLForSubscriberOfferInChildOUFilterWithExtendedInfo(orderRequest, cSubRefId, csof.Soc, pOuRefId, filter)
          if PreExecCheck passes:
              csof.ExtendedInfo[i where Name=="FE_OR_CCBS"].Value = param  ← write-back

Result:
  isSkipped=false → RuleFunctions.Helpers.NextActivity + Logger audit
  isSkipped=true  → RuleFunctions.Helpers.SkipActivity("4")

NOTE: param = orderCurrentActivity.Parameter[0] (the new FE_OR_CCBS value)
NOTE: No JMS event sent to any backend system.
