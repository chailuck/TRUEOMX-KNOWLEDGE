Request_CCBS_L9_CANCEL_SUBS

Cancel an L9 (postpaid) subscriber via CCBS — iterates ParentOU/ChildOU subscribers, uses IntraActivitySequencing sequential fan-out, portOutIndicator set by Channel (MNP=89, else=78)

Priority: 5 ForwardChain: true Target: CCBS (L9 Cancel) Event: CCBS_L9_CANCEL_SUBS Fan-in: IntraActivitySequencing Used in: TNP_CANCEL_SUB (step 4)
§1 — Overview & Purpose

Cancels an L9 (postpaid) subscriber in CCBS via the L9CancelSubscriberRequest API. Iterates all ParentOU and ChildOU subscribers and sends one CCBS_L9_CANCEL_SUBS event per subscriber using IntraActivitySequencing (sequential fan-out: requests are queued and sent one at a time).


EffectiveDate transformation: Before the subscriber loop, the rule calls BN.OrderDataEffectiveDateTransform(ActivityID, EffectiveDate) to adjust the effective date based on the activity. This is applied order-wide, not per-subscriber.

IntraActivitySequencing: Uses ActionRequestEvent + SendFirstRequestEvent (sequential dispatch). Response uses IntraActivitySequencing.ActionResponseEvent — NOT RequestCount-based fan-in.

portOutIndicator: Channel="MNP" → 89 (MNP port-out); else → 78 (non-port). This field controls CCBS MNP handling.

preActivityInfo = "OPENPCH" — hardcoded activity code (Open/Pre-cancel handle). Sent to CCBS for all subscribers.
