Request_CCBS_GET_PAST_DUE_INFO

Backend: CCBS Pattern: Per-Account Loop (IntraActivitySequencing) Priority: 5 ForwardChain: true Generated: 2026-09-14
§1 — Overview & Purpose

Fetches the past-due amount for each Account on the order from CCBS. The retrieved DueAmount is written back to the order data as an AccountExtendedInfo entry with Name="PAST_DUE_AMOUNT" on every account in the order. This step is gated by a PreExecCheck that skips it if PAST_DUE_AMOUNT is already populated.

Uses the IntraActivitySequencing pattern with a per-account loop — one request sent per Account in orderRequest.OrderData.Customer.Account.

[MEDIUM] Double-prefix event name: The event type is Events.OMConsumers.OMXFM.Request.CCBS_CCBS_GET_PAST_DUE_INFO — the "CCBS_" prefix is duplicated. This may indicate a naming inconsistency and should be verified against the ESB channel configuration.
[LOW] LogicalDate concept read but not used: The rule reads a LogicalDate concept into scope but the variable is never referenced in the XSLT payload — likely dead code or a TODO for date-anchored past-due queries.
[NOTE] PreExecCheck scope: The PreExecCheck is evaluated against orderRequest.OrderData (not the full orderRequest). This means the XPath //Account/ExtendedInfo searches under OrderData only.

§5 — Execution Flow Diagram
  1. Compute isActResub
  2. Call PurgePendingRequestsBeforeResubmit(orderRequest, orderCurrentActivity) if isActResub==true
  3. Read PreExecCheck from activity concept (evaluated against orderRequest.OrderData)
  4. Evaluate PreExecCheck XPath on OrderData XML
  5. If fails: SkipActivity("4") (PAST_DUE_AMOUNT already populated)
  6. If passes: isSkipped = false
  7. Loop i = 0 to orderRequest.OrderData.Customer.Account@length - 1
  8. Per iteration: get $account = Account[i], build request via XSLT ($account.AccountID → EntityId)
  9. Assert and dispatch: ActionRequestEvent(reqEvent, orderCurrentActivity)
  10. Emit per-account audit log
  11. After loop: SendFirstRequestEvent(orderCurrentActivity)
  12. Status="1" + SendDataToDB

§18 — Full Source Code
rule Rules.OMConsumers.OMXFM.Request.Request_CCBS_GET_PAST_DUE_INFO {
  attribute { priority = 5; forwardChain = true; }
  then {
    boolean isActResub = (orderCurrentActivity.RequestCount>0 && orderRequest.IsOrderResubmitted);
    if (isActResub) { PurgePendingRequestsBeforeResubmit(orderRequest, orderCurrentActivity); }
    try {
      // NOTE: LogicalDate read but never used in payload
      boolean isSkipped = true;
      String chkRes = "true";
      if (String.length(nextAct.PreExecCheck) > 0) {
        String sXML = Instance.serializeUsingDefaults(orderRequest.OrderData); // NOTE: OrderData, not full orderRequest
        chkRes = XPath.execute("/("+chkXPath+")", sXML, "ns0=...");
      }
      if (String.equals(chkRes, "true")) {
        isSkipped = false;
        for (int i = 0; i < orderRequest.OrderData.Customer.Account@length; i++) {
          Account account = orderRequest.OrderData.Customer.Account[i];
          Events...CCBS_CCBS_GET_PAST_DUE_INFO reqEvent = Event.createEvent("xslt://...");
          /* XSLT: ns5:GetPastDueInfoRequest / ns4:ClEntityIdInfo — see §9 */
          /* Params: $orderRequest, $account, $globalVariables */
          Event.assertEvent(reqEvent);
          IntraActivitySequencing.ActionRequestEvent(reqEvent, orderCurrentActivity);
          Event.Ext.sendEventImmediate(logEvent);
        }
        IntraActivitySequencing.SendFirstRequestEvent(orderCurrentActivity);
        orderCurrentActivity.Status = GetActivityStatusString("1", false);
        SendDataToDB(orderRequest);
      } else { SkipActivity(orderRequest, orderCurrentActivity, "4"); }
    } catch (Exception ae) { HandleActivityException(orderRequest, orderCurrentActivity, ae, ""); }
  }
}
§19 — Response Message Rule

§19.1 Overview

Creates a CCBS_GetPastDueInfoRes response concept, extracts DueAmount from CCBS response, writes it as AccountExtendedInfo.PAST_DUE_AMOUNT on all accounts in the order (not just the account that was queried), logs, and advances fan-in via IntraActivitySequencing.
