Request_CCBS_SHARE_PLAN_ADD_PROPO_MNP

Adds MNP proposition offers (FE=FE, TR_CONTRACT_NUMBER present, not RMVX) to the new SharePlan child subscriber in CCBS

Priority: 5Target: CCBS Event: CCBS_UPDATE_SUBSCRIBERScope: ParentOU only Target Subscriber: NEW_SHAREPLAN_CHILD_ID
§1 — Overview & Purpose
CCBS_SHARE_PLAN_ADD_PROPO_MNP adds MNP proposition offers to the new SharePlan child subscriber in CCBS. It filters subscriber offers to those where FE_OR_CCBS=FE AND OfferName≠RMVX00000000001 AND ParameterInfo[TR_CONTRACT_NUMBER] exists. The target subscriber is identified by ExtendedInfo[NEW_SHAREPLAN_CHILD_ID] (the newly created CCBS child subscriber ID). Uses CCBS_UPDATE_SUBSCRIBER event and includes ParameterInfo pass-through.

Key gate: If NEW_SHAREPLAN_CHILD_ID is empty, no request is sent (subscriber silently skipped).
Offer exclusion: RMVX00000000001 is explicitly excluded — this is a removal offer that should not be added to the child subscriber.
