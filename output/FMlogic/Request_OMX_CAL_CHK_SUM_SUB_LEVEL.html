Request_OMX_CAL_CHK_SUM_SUB_LEVEL

Backend: Internal (OMX) Pattern: Per-Subscriber Computation Priority: 5 ForwardChain: true Generated: 2026-09-14
§1 — Overview & Purpose

An internal computation rule — no external backend call is made. For each eSIM subscriber (SIM_TYPE="B"), it extracts the ICC_ID ExtendedInfo value, computes the Luhn check digit using RuleFunctions.Helpers.Luhn(), and appends the result as a new ICC_ID_CHG_SUM ExtendedInfo entry (value = iccId + luhnDigit). This prepares the ICCID with check digit needed for subsequent SM-DP+ operations.

Rule location: OMXOM/OMX_CAL_CHK_SUM_SUB_LEVEL.rule — note this is in the OMXOM folder (internal orchestration), NOT the OMXFM/Request folder like standard FM request rules.
[MEDIUM] Dead code — paramValue (PROJ): Line 31 reads the PROJ parameter via GetActivityParamValueFromKey but the value is never used in the computation. Remove in migration.
[LOW] Misleading AUDIT_TRACE: "Request Sent for OMX_CAL_CHK_SUM_SUB_LEVEL" — there is no external request. Should read "ICC_ID checksum computed for subscribers" or similar.

§5 — Execution Flow Diagram
  1. If isActResub: call PurgePendingRequestsBeforeResubmit
  2. Read PROJ parameter via GetActivityParamValueFromKey (value unused — dead code)
  3. Loop POU subscribers: for each, evaluate PreExecCheck (SIM_TYPE="B" filter)
  4. Extract ICC_ID from subscriber.ExtendedInfo[Name="ICC_ID"]/Value via XPath
  5. If ICC_ID non-empty: compute iccIdCheckSum = Luhn(iccId)
  6. Create SubscriberExtendedInfo concept with Name="ICC_ID_CHG_SUM", Value=iccId+checkSum
  7. Append to subscriber.ExtendedInfo
  8. Emit audit log event; set isSkipped = false
  9. Repeat for COU subscribers (same logic, uses GetXMLForSubscriberInChildOU for PreExecCheck)
  10. If !isSkipped: call NextActivity(); else SkipActivity("4")
  11. On exception: HandleActivityException
§6 — Rule Action (THEN) — Step-by-Step Logic

§6.1 PreExecCheck Per Subscriber

From ProcessConfig (step 11):

count(//Subscriber/ResourceInfo[ResourceName='SIM_TYPE' and ValuesArray="B"]) > 0

Evaluated per subscriber using GetXMLForSubscriber (POU) or GetXMLForSubscriberInChildOU (COU). Filters to eSIM subscribers only.

§18 — Full Source Code
rule Rules.OMConsumers.OMXOM.OMX_CAL_CHK_SUM_SUB_LEVEL {
  attribute { priority = 5; forwardChain = true; }
  declare {
    Concepts.OrderRequest.OrderRequest orderRequest;
    Concepts.OM.ProcessConfig.Activity orderCurrentActivity;
  }
  when { /* WAITING + ActivityID + NextActivityID match */ }
  then {
    boolean isActResub = (...);
    try {
      if (isActResub) PurgePendingRequestsBeforeResubmit(orderCurrentActivity);
      String paramValue = GetActivityParamValueFromKey(orderCurrentActivity, "PROJ"); // DEAD CODE
      boolean isSkipped = true;

      // POU + COU loop — identical structure
      for (int i=0; i<pOuLen; i++) {
        for (int iSub=0; iSub<subLen; iSub++) {
          // Evaluate PreExecCheck per subscriber
          if (chkRes == "true") {
            String iccId = XPath.evalAsString("$subscriber/ExtendedInfo[Name=\"ICC_ID\"]/Value");
            if (String.length(iccId) > 0) {
              String iccIdCheckSum = RuleFunctions.Helpers.Luhn(iccId);
              SubscriberExtendedInfo iccIdChgSum = Instance.createInstance("xslt://...");
              /* XSLT sets extId=concat(iccId,":ICC_ID_CHG_SUM",subscriber/@extId), Name="ICC_ID_CHG_SUM" */
              iccIdChgSum.Value = iccId + iccIdCheckSum;
              subscriber.ExtendedInfo[...] = iccIdChgSum;
              Event.Ext.sendEventImmediate("xslt://Logger..."); // audit
              isSkipped = false;
            }
          }
        }
      }

      if (!isSkipped) {
        RuleFunctions.Helpers.NextActivity(orderRequest, orderCurrentActivity);
      } else {
        RuleFunctions.Helpers.SkipActivity(orderRequest, orderCurrentActivity, "4");
      }
    } catch (Exception ae) {
      RuleFunctions.Helpers.HandleActivityException(orderRequest, orderCurrentActivity, ae, "");
    }
  }
}
