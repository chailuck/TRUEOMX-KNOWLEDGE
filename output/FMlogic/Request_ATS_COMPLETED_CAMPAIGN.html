Request_ATS_COMPLETED_CAMPAIGN

ATS Campaign Completion notification — minimal payload using TRUELIFE_ID and CAMPAIGN_CODE
Backend: ATS Author: Chayatorn P. Priority: 5 Pattern: FIRE-AND-FORGET No write-back to order
§1 — Overview & Purpose
ATS_COMPLETED_CAMPAIGN notifies ATS that the campaign registration is complete by sending requestName="UpdateCompletedCampaign". Uses the same ATS_SUBMIT_CAMPAIGN event type as FM28 but with a simpler payload — no subscriber loop, no customer name fields.
Fire-and-forget: Uses Event.Ext.sendEventImmediate + manual RequestCount++. Fan-in: count("000") == RequestCount.
Depends on FM28: Uses ExtInfo[TRUELIFE_ID].Value written by FM28 response. If FM28 was skipped, TRUELIFE_ID will be empty and ATS may reject the request.
No response write-back to order: ResponseBase (4 standard fields) only. Campaign completion state is tracked in ATS, not in the order.
