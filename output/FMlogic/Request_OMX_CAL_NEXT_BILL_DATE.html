OMX_CAL_NEXT_BILL_DATE

Internal OMX calculation — computes the subscriber's next bill date from the BillCycleNo, stamps SubscriberOffers with ExpirationDate and SBM_NO_PROVISIONING=Y flag, then immediately advances the orchestration
Priority: 5 ForwardChain: true Type: Internal Calculation (No Backend Call) Location: Rules/OMConsumers/OMXOM Generated: 2026-08-13
§1 — Overview & Purpose
This is a pure internal OMX computation rule — no external backend call, no JMS message, no response rulefunction. It completes synchronously and immediately calls NextActivity() to advance the orchestration.

When the order reaches the OMX_CAL_NEXT_BILL_DATE activity, this rule calculates when the subscriber's next billing cycle date falls, then iterates over every qualifying SubscriberOffers entry in the order (both POU and COU hierarchy). For each qualifying offer it:

  1. Sets psof.ExpirationDate = nextBillDate — the offer will expire at the next bill date
  2. Appends a SubscriberOffersExtendedInfo with Name="SBM_NO_PROVISIONING", Value="Y" — signals downstream SBM steps to skip immediate provisioning and let the offer expire naturally at cycle end

The qualification gate is driven by PreExecCheck evaluated against an XML snapshot that includes the offer's FE_OR_CCBS tag — so only offers matching a specific source (CCP or CCBS) are stamped, depending on what PreExecCheck specifies for this order type.

Business Purpose: For POSTPAID_REMOVE_OFFER_SUB, this step determines whether a removed offer should be terminated immediately or deferred to the next billing cycle. Setting SBM_NO_PROVISIONING=Y instructs SBM to suppress immediate deactivation.

§5 — Execution Flow Diagram
1
Load LogicalDate: Look up LogicalDate concept by extId. If LogicalDate field is blank/empty → use DateTime.now(). Otherwise parse it as yyyy-MM-dd'T'HH:mm:ssXXX.
2
Get BillCycleNo: Read orderRequest.OrderData.Customer.BillCycleNo. This is the day-of-month on which the customer is billed (e.g., "5" = 5th of each month).
3
Calculate next bill date: Call GetNextBillDate(logicalDate, nextBill) → internally calls ConvertBillCycleDate(billCycle) to get the day string, builds a date for this month, then adds 1 month if current date is already past the bill date.
4
Read PreExecCheck: orderCurrentActivity.PreExecCheck — the XPath expression used to filter which offers to stamp. May be empty (stamp all).
5
POU Offer loop: Iterate ParentOU[p] → Subscriber[ps] → SubscriberOffers[o]. For each offer: read FE_OR_CCBS ExtendedInfo as filter. Build subscriber-offer XML via GetXMLForSubscriberOfferFilterWithExtendedInfo(). Evaluate PreExecCheck. If passes → stamp ExpirationDate + SBM_NO_PROVISIONING=Y.
6
COU Offer loop: Same for ParentOU[p] → ChildOU[c] → Subscriber[cs] → SubscriberOffers[o], using GetXMLForSubscriberOfferInChildOUFilterWithExtendedInfo().
7
Advance orchestration: If any offer was stamped → call NextActivity() (marks current activity COMPLETE, advances to next) + log audit event. If all skipped → SkipActivity("4").
8
Exception: HandleActivityException().

§7 — Data Extraction & Calculation Logic

Bill Date Calculation (GetNextBillDate)

// Step 1: Convert BillCycleNo to day-of-month string
String billCycleDate = RuleFunctions.Helpers.ConvertBillCycleDate(billCycle); // e.g. "5" → "05"

// Step 2: Build date for current month
DateTime nextBillDate = DateTime.parseString(
    billCycleDate + "-" + (DateTime.getMonth(currentDate) + 1) + "-" + DateTime.getYear(currentDate),
    "dd-MM-yyyy");

// Step 3: If today is already past the bill date, roll forward one month
if (currentDate >= nextBillDate) {
    nextBillDate = DateTime.addMonth(nextBillDate, 1);
}
return nextBillDate;

Example: BillCycleNo="5", today=2026-08-13 → bill date this month = 2026-08-05 (already past) → next bill date = 2026-09-05.

Offer Qualification Filter

For each SubscriberOffers:

// 1. Read the source tag from the offer's ExtendedInfo
String filter = XPath.evalAsString("$psof/ExtendedInfo[Name=\"FE_OR_CCBS\"]/Value"); // "CCP" or "CCBS"

// 2. Build subscriber-offer XML snapshot including the filter value
String sXML = RuleFunctions.Helpers.GetXMLForSubscriberOfferFilterWithExtendedInfo(orderRequest, pSubRefId, psof.Soc, filter);

// 3. Evaluate PreExecCheck XPath against the XML
chkRes = XPath.execute("/("+chkXPath+")", sXML, "ns0=...");

The FE_OR_CCBS filter allows the PreExecCheck to discriminate between CCP-sourced offers (from GET_PROFILE_FROM_CCP_ALL) and CCBS-sourced offers.

SBM_NO_PROVISIONING Stamp (XSLT)

<!-- Creates SubscriberOffersExtendedInfo -->

§18 — Full Source Code
rule Rules.OMConsumers.OMXOM.OMX_CAL_NEXT_BILL_DATE {
  attribute { priority = 5; forwardChain = true; }
  declare {
    Concepts.OrderRequest.OrderRequest orderRequest;
    Concepts.OM.ProcessConfig.Activity orderCurrentActivity;
  }
  when {
    orderCurrentActivity@extId == orderRequest.ProcessFlow.NextActivityName;
    orderCurrentActivity.ActivityID == "OMX_CAL_NEXT_BILL_DATE";
    orderRequest.ProcessFlow.NextActivityID == "OMX_CAL_NEXT_BILL_DATE";
    orderCurrentActivity.Status == "WAITING";
  }
  then {
    try {
      DateTime logicalDate;
      Concepts.OM.LogicalDate logicalDateRes = Instance.getByExtIdByUri("LogicalDate", "/Concepts/OM/LogicalDate");

      if(String.length(String.trim(logicalDateRes.LogicalDate)) <= 0){
        logicalDate = DateTime.now();
      } else {
        logicalDate = DateTime.parseString(logicalDateRes.LogicalDate, "yyyy-MM-dd'T'HH:mm:ssXXX");
      }

      String nextBill = orderRequest.OrderData.Customer.BillCycleNo;
      // (Parameter override commented out)

      boolean isSkipped = true;
      DateTime nextBillDate = RuleFunctions.Helpers.GetNextBillDate(logicalDate, nextBill);

      String chkXPath = orderCurrentActivity.PreExecCheck;
      int pouLen = orderRequest.OrderData.Customer.ParentOU@length;
      for(int p = 0; p < pouLen; p++) {
        String pOuRefId = orderRequest.OrderData.Customer.ParentOU[p].RefId;

        // POU Subscriber loop
        for (int ps = 0; ps < pSubLen; ps++) {
          for (int o = 0; o < psofLen; o++) {
            Concepts.OrderRequest.OrderElements.SubscriberOffers psof = ...Subscriber[ps].SubscriberOffers[o];
            String filter = XPath.evalAsString("$psof/ExtendedInfo[Name=\"FE_OR_CCBS\"]/Value");
            String chkRes = "true";
            if (String.length(chkXPath) > 0) {
              String sXML = RuleFunctions.Helpers.GetXMLForSubscriberOfferFilterWithExtendedInfo(orderRequest, pSubRefId, psof.Soc, filter);
              chkRes = XPath.execute("/("+chkXPath+")", sXML, "ns0=...");
            }
            if (String.equals(chkRes, "true")) {
              Concepts.OrderRequest.OrderElements.ExtendedInfos.SubscriberOffersExtendedInfo sbmProv =
                Instance.createInstance(/* XSLT: Name=SBM_NO_PROVISIONING, Value=Y — see §9 */);
              psof.ExtendedInfo[psof.ExtendedInfo@length] = sbmProv;
              psof.ExpirationDate = nextBillDate;
              isSkipped = false;
            }
          }
        }
        // COU loop — identical pattern, uses GetXMLForSubscriberOfferInChildOUFilterWithExtendedInfo
      }

      if(!isSkipped) {
        RuleFunctions.Helpers.NextActivity(orderRequest, orderCurrentActivity);
        // + audit log event
      } else {
        RuleFunctions.Helpers.SkipActivity(orderRequest, orderCurrentActivity, "4");
      }
    } catch (Exception ex) {
      RuleFunctions.Helpers.HandleActivityException(orderRequest, orderCurrentActivity, ex, "");
    }
  }
}
