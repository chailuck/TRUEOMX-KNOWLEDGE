Request_OMX_SUBMIT_POSTPAID_CHANGE_PACKAGE

OMX — Submit Postpaid Change Package as Child Orders per Subscriber

Priority: 5 forwardChain: true Backend: OMX Event: OMX_CREATE_CHILD_ORDER Loop: ParentOU + ChildOU Subscribers Generated: 2026-09-23
§1 — Overview & Purpose

Creates child OMX orders for each subscriber (across ParentOU + ChildOU) to change their postpaid package. The OFFER parameter is parsed from a comma-separated key=value string into offer components: offerName, soc, serviceType, reasonCode, userText.

⚠ Naming anomaly: ActivityID is OMX_SUBMIT_POSTPAID_CHANGE_PACKAGE but JMS event dispatched is OMX_CREATE_CHILD_ORDER.
💡 childIndex: A global counter incremented across all subscribers (ParentOU + ChildOU combined), not reset per OU. Used in orderId = concat(OrderID, "-", childIndex) and channel = concat(Channel, "-OMX").

ExtendedInfo written: MAIN_TRACKING_ID=OMXTrackingId, SBM_CHANNEL="OMX".

§5 — Execution Flow
  1. Check resubmit; evaluate PreExecCheck
  2. Read parameters: ORDER_TYPE (required), OFFER (required)
  3. Validate — throw exception if ORDER_TYPE or OFFER missing
  4. Parse OFFER: String.split(offerParam, ",") → per token: String.split(token, "=") → map to offerName, soc, serviceType, reasonCode, userText
  5. childIndex = 0
  6. Outer loop: ParentOU[p].Subscriber[s] → send child order; childIndex++
  7. Inner loop: ChildOU[c][under ParentOU[p]] Subscriber[s] → send child order; childIndex++
  8. Set WAITING_RESPONSE; persist to DB
§7 — OFFER Parameter Parsing

The OFFER parameter is a comma-separated list of key=value pairs. Example: offerName=POSTPAID_BASIC,soc=SOC_001,serviceType=80,reasonCode=CHG,userText=Change Package

If OFFER or ORDER_TYPE is missing: throw new Exception("Required parameter missing")
