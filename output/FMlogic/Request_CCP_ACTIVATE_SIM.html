Request_CCP_ACTIVATE_SIM

FM Logic Documentation — CCP SIM Activation (IntraActivitySequencing)
Rule: Rules.OMConsumers.OMXFM.Request.Request_CCP_ACTIVATE_SIM Priority: 5 Backend: CCP (Charging & Control Platform) Pattern: IntraActivitySequencing Generated: 2026-09-09
§1 — Overview & Purpose

CCP_ACTIVATE_SIM sends an ActivateSimRequest to the CCP (Charging & Control Platform) for each subscriber in the order's ParentOU list. It uses the IntraActivitySequencing pattern — requests are queued and dispatched one at a time to avoid parallel flooding of the CCP system. CCP credentials (CCP_USER / CCP_PASSWORD) are sourced from order-level ExtendedInfo. A short requestId is generated from the order's Channel field.

Critical Bug — Missing ActionResponseEvent: The response rulefunction does NOT call IntraActivitySequencing.ActionResponseEvent after each response. For multi-subscriber orders, only the first subscriber's SIM activation request will ever be sent — subsequent queued requests are never dispatched. The response RF falls back to a plain count-based fan-in (RequestCount == Response@length) which will never reach equality when N>1 unless all N responses are received (which they cannot be, since only 1 is ever sent).

§5 — Execution Flow Diagram
  1. Resubmit purge — if isActResub: call PurgePendingRequestsBeforeResubmit(orderCurrentActivity) to clear any previous queue state
  2. Load activity config — Instance.getByExtIdByUri(NextActivityName) → nextAct
  3. PreExecCheck — if nextAct.PreExecCheck non-empty: serialize full orderRequest to XML → XPath evaluate → sets chkRes
  4. Extract CCP credentials — iterate orderRequest.OrderData.ExtendedInfo[] looking for CCP_USER and CCP_PASSWORD keys
  5. Compute requestId — "OMX" + Channel + "000000000" → truncate to 12 chars
  6. Per-subscriber loop — iterate ParentOU[i].Subscriber[j]:
    • Build CCP_ACTIVATE_SIM event with ActivateSimRequest payload (user, password, msisdn, requestId)
    • Event.assertEvent(reqEvent) — asserts event into working memory
    • IntraActivitySequencing.ActionRequestEvent(reqEvent, orderCurrentActivity) — enqueues event for sequential dispatch
    • Send audit log (unconditionally per iteration)
    • Set isSkipped = false
  7. Dispatch first request — IntraActivitySequencing.SendFirstRequestEvent(orderCurrentActivity) — sends only the first queued request
  8. Status transition — GetActivityStatusString("1", false) + SendDataToDB
Audit log inside subscriber loop: The audit log send (Event.Ext.sendEventImmediate(Logger...)) occurs inside the per-subscriber loop on each iteration — so N audit events are sent for N subscribers even though only the first JMS request is dispatched. The audit payload copies the full $reqEvent structure (no payload filtering).
PreExecCheck scope: The PreExecCheck is evaluated once at the activity level using the entire serialized orderRequest. This differs from per-offer PreExecCheck patterns used by CAT_GET_SWF. If PreExecCheck fails, ALL subscriber activations are skipped.
§6 — Rule Action (THEN) — Annotated Logic
boolean isActResub = (orderCurrentActivity.RequestCount > 0 && orderRequest.IsOrderResubmitted);

// Purge stale queue on resubmit
if(isActResub) {
    RuleFunctions.Helpers.IntraActivitySequencing.PurgePendingRequestsBeforeResubmit(orderCurrentActivity);
}

try {
    Concepts.OM.ProcessConfig.Activity nextAct = Instance.getByExtIdByUri(...);
    boolean isSkipped = true;
    String chkRes = "true";

    // Activity-level PreExecCheck using full orderRequest serialization
    if(String.length(nextAct.PreExecCheck) > 0) {
        String sXML = Instance.serializeUsingDefaults(orderRequest);
        String chkXPath = nextAct.PreExecCheck;
        chkRes = XPath.execute("/("+chkXPath+")", sXML, "ns0=...");
    }

    if(String.equals(chkRes, "true")) {
        // Extract CCP credentials from OrderData.ExtendedInfo
        String ccp_user = "";
        String ccp_password = "";
        for(int i = 0; i < orderRequest.OrderData.ExtendedInfo@length; i++) {
            if(String.equals(exInfo.Name, "CCP_USER"))     ccp_user = exInfo.Value;
            if(String.equals(exInfo.Name, "CCP_PASSWORD")) ccp_password = exInfo.Value;
        }

        // requestId = "OMX" + Channel + "000000000" truncated to 12 chars
        String requestId = "OMX" + orderRequest.OrderData.Channel + "000000000";
        requestId = String.substring(requestId, 0, 12);

        // Per-subscriber dispatch loop
        int pOuLen = orderRequest.OrderData.Customer.ParentOU@length;
        for(int i = 0; i < pOuLen; i++) {
            String pOuRefId = orderRequest.OrderData.Customer.ParentOU[i].RefId;
            for(int j = 0; j < ou.Subscriber@length; j++) {
                Concepts.OrderRequest.OrderElements.Subscriber sub = ou.Subscriber[j];
                // [XSLT builds ActivateSimRequest — see §9.7]
                Events.OMConsumers.OMXFM.Request.CCP_ACTIVATE_SIM reqEvent = Event.createEvent("xslt://...");
                Event.assertEvent(reqEvent);
                RuleFunctions.Helpers.IntraActivitySequencing.ActionRequestEvent(reqEvent, orderCurrentActivity);
                // Audit log per-subscriber (unconditional — no AllowWriteLog check!)
                long pid = System.nanoTime();
                Event.Ext.sendEventImmediate(Event.createEvent("xslt://Logger..."));
                isSkipped = false;
            }
        }
    }

    if(!isSkipped) {
        RuleFunctions.Helpers.IntraActivitySequencing.SendFirstRequestEvent(orderCurrentActivity);
        orderCurrentActivity.Status = RuleFunctions.Helpers.GetActivityStatusString("1", false);
        RuleFunctions.Helpers.SendDataToDB(orderRequest);
    } else {
        RuleFunctions.Helpers.SkipActivity(orderRequest, orderCurrentActivity, "4");
    }
} catch(Exception ae) {
    RuleFunctions.Helpers.HandleActivityException(orderRequest, orderCurrentActivity, ae, "");
}

requestId Generation

String requestId = "OMX" + orderRequest.OrderData.Channel + "000000000";
requestId = String.substring(requestId, 0, 12);
// Example: Channel="RETAIL" → "OMXRETAIL000000000" → substring(0,12) = "OMXRETAIL000"
// Example: Channel="DT"    → "OMXDT000000000"     → substring(0,12) = "OMXDT0000000"
requestId collision risk: The requestId is derived only from the Channel field — all orders from the same channel get the same requestId. This is NOT unique per request or per subscriber. CCP may use requestId for deduplication; sending the same requestId for multiple activations could cause silent failures or idempotency conflicts.

§17 — Migration Notes & Recommendations

Functional Requirements

RefRequirement
R1Send ActivateSimRequest to CCP for each ParentOU subscriber
R2Apply activity-level PreExecCheck before any dispatch (serializes full orderRequest)
R3Retrieve CCP_USER and CCP_PASSWORD from order ExtendedInfo

Design Risks

RiskSeverityMitigation
Critical Bug: Missing ActionResponseEvent — Response RF does NOT call IntraActivitySequencing.ActionResponseEvent. For orders with more than 1 subscriber, only the first SIM activation is sent; remaining queued requests are never dispatched. The fan-in check (RequestCount == Response@length) will also never complete because subsequent subscribers' responses will never arrive. CRITICAL Add IntraActivitySequencing.ActionResponseEvent(currActivity) call in response RF before the fan-in return; change fan-in to use its return value

No ChildOU subscriber support: Only ParentOU[*].Subscriber[*] is iterated. ChildOU subscribers are never activated. MEDIUM Add ChildOU subscriber loop (same pattern as CCP_ADD_HOME_ZONE and CAT_GET_SWF)
Plaintext password in audit log: Request audit sends full $reqEvent payload (includes <password>) when WritePayload="true". The password is not masked. MEDIUM Mask the password field in the audit XSLT or log only the msisdn/requestId fields
Unconditional request audit: Request audit log fires for every subscriber regardless of AllowWriteLog(OrderType). Inconsistent with other FMs and may cause excess audit volume for non-loggable order types. LOW Wrap request audit in if(AllowWriteLog(orderRequest.OrderData.OrderType))
§18 — Full Source Code (Request Rule)
/**
 * @description
 * @author DESKTOP-HINKNF3
 */
rule Rules.OMConsumers.OMXFM.Request.Request_CCP_ACTIVATE_SIM {
    attribute { priority = 5; forwardChain = true; }
    declare {
        Concepts.OrderRequest.OrderRequest orderRequest;
        Concepts.OM.ProcessConfig.Activity orderCurrentActivity;
    }
    when {
        orderCurrentActivity@extId == orderRequest.ProcessFlow.NextActivityName;
        orderCurrentActivity.ActivityID == "CCP_ACTIVATE_SIM";
        orderRequest.ProcessFlow.NextActivityID == "CCP_ACTIVATE_SIM";
        orderCurrentActivity.Status == "WAITING";
    }
    then {
        boolean isActResub = (orderCurrentActivity.RequestCount > 0 && orderRequest.IsOrderResubmitted);
        if(isActResub)
            RuleFunctions.Helpers.IntraActivitySequencing.PurgePendingRequestsBeforeResubmit(orderCurrentActivity);

        try {
            Concepts.OM.ProcessConfig.Activity nextAct = Instance.getByExtIdByUri(
                orderRequest.ProcessFlow.NextActivityName, "/Concepts/OM/ProcessConfig/Activity");
            boolean isSkipped = true;
            String chkRes = "true";

            // Activity-level PreExecCheck (full orderRequest serialization)
            if(String.length(nextAct.PreExecCheck) > 0) {
                String sXML = Instance.serializeUsingDefaults(orderRequest);
                chkRes = XPath.execute("/("+nextAct.PreExecCheck+")", sXML, "ns0=...");
            }

            if(String.equals(chkRes, "true")) {
                // Extract CCP credentials from ExtendedInfo
                String ccp_user = "", ccp_password = "";
                for(int i = 0; i < orderRequest.OrderData.ExtendedInfo@length; i++) {
                    Concepts.OrderRequest.OrderElements.ExtendedInfos.OrderDataExtendedInfo exInfo =
                        orderRequest.OrderData.ExtendedInfo[i];
                    if(String.equals(exInfo.Name, "CCP_USER"))     ccp_user = exInfo.Value;
                    if(String.equals(exInfo.Name, "CCP_PASSWORD")) ccp_password = exInfo.Value;
                }

                // requestId = "OMX" + Channel (truncated to 12 chars)
                String requestId = String.substring(
                    "OMX" + orderRequest.OrderData.Channel + "000000000", 0, 12);

                // Per-subscriber dispatch
                int pOuLen = orderRequest.OrderData.Customer.ParentOU@length;
                for(int i = 0; i < pOuLen; i++) {
                    Concepts.OrderRequest.OrderElements.ParentOU ou = orderRequest.OrderData.Customer.ParentOU[i];
                    String pOuRefId = orderRequest.OrderData.Customer.ParentOU[i].RefId;
                    for(int j = 0; j < ou.Subscriber@length; j++) {
                        Concepts.OrderRequest.OrderElements.Subscriber sub = ou.Subscriber[j];
                        // [XSLT builds ActivateSimRequest with user, password, msisdn, requestId — see §9.7]
                        Events.OMConsumers.OMXFM.Request.CCP_ACTIVATE_SIM reqEvent =
                            Event.createEvent("xslt://...");
                        Event.assertEvent(reqEvent);
                        RuleFunctions.Helpers.IntraActivitySequencing.ActionRequestEvent(reqEvent, orderCurrentActivity);
                        // Audit log — NOTE: no AllowWriteLog gate here (unlike most FMs)
                        long pid = System.nanoTime();
                        Event.Ext.sendEventImmediate(Event.createEvent("xslt://Logger..."));
                        isSkipped = false;
                    }
                }
            }

            if(!isSkipped) {
                RuleFunctions.Helpers.IntraActivitySequencing.SendFirstRequestEvent(orderCurrentActivity);
                orderCurrentActivity.Status = RuleFunctions.Helpers.GetActivityStatusString("1", false);
                RuleFunctions.Helpers.SendDataToDB(orderRequest);
            } else {
                RuleFunctions.Helpers.SkipActivity(orderRequest, orderCurrentActivity, "4");
            }
        } catch(Exception ae) {
            RuleFunctions.Helpers.HandleActivityException(orderRequest, orderCurrentActivity, ae, "");
        }
    }
}
§19 — Response Message Rule (Response_CCP_ACTIVATE_SIM)

§19.1 — Overview

Creates a ResponseBase concept from the CCP_ACTIVATE_SIM response event, appends it to currActivity.Response[], logs the response (if allowed), then checks fan-in completion via RequestCount == Response@length. Returns "true" when all responses received, "false" otherwise.

Critical Bug: This response RF does NOT call IntraActivitySequencing.ActionResponseEvent(currActivity) to dispatch the next queued request. With IntraActivitySequencing in the request rule, subsequent requests (for orders with N>1 subscribers) will never be sent. This effectively makes CCP_ACTIVATE_SIM only work for single-subscriber orders.
