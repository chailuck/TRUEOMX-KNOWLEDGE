Request_SBM_FUP_CREATE_GROUP

Creates FUP (Fair Usage Policy) groups in SBM for each OU with qualifying FE special offer indicators
System: SBM Priority: 5 Author: SathidP-PC function_id: 104300001 Pattern: Dual-loop POU/COU + direct send Fan-in: RequestCount == successResponseCount Generated: 2026-09-15
§1 Overview & Purpose

This rule creates FUP (Fair Usage Policy) groups in SBM by sending SBM_FUP_DO_SERVICE requests with function_id=104300001 for each ParentOU and ChildOU that passes the PreExecCheck. Before sending, it scans the OU's Agreement.Offers to find eligible FUP offers — those with a non-empty SPECIAL_OFFER_INDICATOR ExtendedInfo value, FE_OR_CCBS="FE", and whose indicator value matches any entry in the global FUPCreateGroupOfferInd list. The matching OfferNames are concatenated into a comma-separated fupElement string passed to SBM.

Unlike most CCBS FMs, this rule uses direct send (Event.Ext.sendEventImmediate) with manual RequestCount++ rather than the assertEvent + ActionRequestEvent IntraActivitySequencing pattern. There is no CompletionStatus==2 skip check on resubmit; however, it does purge pending requests before resending. If no eligible FUP offer is found for a qualifying OU, an OMX_DATA_ERROR exception is thrown.

§5 Execution Flow Diagram
1
Resubmit + Init — If isActResub, call PurgePendingRequestsBeforeResubmit. Set function_id="104300001", isSkipped=true.
2
Outer POU Loop — Iterates Customer.ParentOU[].
3
POU PreExecCheck — Calls GetXMLForOU(orderRequest, pOURefId) and evaluates gate. Skip POU if gate returns false.
4
POU FUP Offer Scan — Iterates ParentOU[iPOU].Agreement.Offers[]:
  • Read ExtendedInfo[Name="SPECIAL_OFFER_INDICATOR"]/Value
  • Read ExtendedInfo[Name="FE_OR_CCBS"]/Value
  • Include if: specialOfferInd.length > 0 AND fe_or_ccbs == "FE" AND BRMS.AnyIn(FUPCreateGroupOfferInd, specialOfferInd)
  • Append OfferName to comma-separated fupElement string
5
FUP Guard — If fupElement == "", throw OMX_DATA_ERROR: "There is no FUP offer. OU: <OUId>".
6
POU Send — Build SBM_FUP_DO_SERVICE event (POU variant: currPOU). Event.Ext.sendEventImmediate(reqEvent). If not resubmit: RequestCount++. Log audit. Set isSkipped=false.
7
Inner COU Loop — Iterates ParentOU[iPOU].ChildOU[], same pattern as steps 3–6 using GetXMLForChildOU and COU variant event.
8
Post-loop decision — If !isSkipped → Status="1", SendDataToDB. Else → SkipActivity("4").
9
Exception — catch(Exception ae) → HandleActivityException.

for(int iOffer=0; iOffer < offerLen; iOffer++) {
    String specialOfferInd = XPath.evalAsString("$currOffer/ExtendedInfo[Name='SPECIAL_OFFER_INDICATOR']/Value");
    String fe_or_ccbs     = XPath.evalAsString("$currOffer/ExtendedInfo[Name='FE_OR_CCBS']/Value");

       && String.equals(fe_or_ccbs, "FE")
       && RuleFunctions.Helpers.BRMS.AnyIn(FUPCreateGroupOfferInd, specialOfferInd)) {
        fupElement = (fupElement.equals("")) ? OfferName : fupElement + "," + OfferName;
    }
}
if(fupElement == "")
    throw Exception.newException("OMX_DATA_ERROR",
        String.format("There is no FUP offer. OU: %s", currPOU.OUId), null);

    Event.createEvent("xslt://..."); /* §9.8 Variant ① POU */

§7 FUP Offer Selection Logic

For each Agreement.Offers entry in the OU:

ConditionSource
SPECIAL_OFFER_INDICATOR is non-emptyExtendedInfo[Name="SPECIAL_OFFER_INDICATOR"]/Value
FE_OR_CCBS equals "FE"ExtendedInfo[Name="FE_OR_CCBS"]/Value
BRMS.AnyIn matchBRMS.AnyIn($globalVariables/OMX_OM/FUP/FUPCreateGroupOfferInd, specialOfferInd)

Matching offers are appended as comma-separated OfferName values into fupElement. If fupElement remains empty after iterating all offers, an OMX_DATA_ERROR exception is thrown and activity processing stops.

Guard: If no eligible FUP offer found → throw Exception.newException("OMX_DATA_ERROR", "There is no FUP offer. OU: " + OUId, null) — activity fails immediately.

§17 Migration Notes & Recommendations

Functional Requirements

  • R1: Dual-loop POU/COU with PreExecCheck gate at each level
  • R2: FUP offer eligibility: SPECIAL_OFFER_INDICATOR non-empty, FE_OR_CCBS="FE", matches FUPCreateGroupOfferInd allowlist
  • R3: function_id=104300001 static; fupElement is comma-separated eligible OfferNames
  • R4: JMSCorrelationID = orderRequest@extId attribute (NOT OMXTrackingId)
  • R5: Manual RequestCount++ instead of ActionRequestEvent sequencing
  • R6: Throw OMX_DATA_ERROR if no FUP offer found for an eligible OU

/**
 * @description
 * @author SathidP-PC
 */
rule Rules.OMConsumers.OMXFM.Request.Request_SBM_FUP_CREATE_GROUP {
    attribute {
        priority = 5;
        forwardChain = true;
    }
    declare {
        Concepts.OrderRequest.OrderRequest orderRequest;
        Concepts.OM.ProcessConfig.Activity orderCurrentActivity;
    }
    when {
        orderCurrentActivity@extId == orderRequest.ProcessFlow.NextActivityName;
        orderCurrentActivity.ActivityID == "SBM_FUP_CREATE_GROUP";
        orderRequest.ProcessFlow.NextActivityID == "SBM_FUP_CREATE_GROUP";
        orderCurrentActivity.Status == "WAITING";
    }
    then {
        boolean isActResub = (orderCurrentActivity.RequestCount > 0
                              && orderRequest.IsOrderResubmitted);
        try {
            Concepts.OM.ProcessConfig.Activity nextAct =
                Instance.getByExtIdByUri(orderRequest.ProcessFlow.NextActivityName, ...);
            if(isActResub)
                IntraActivitySequencing.PurgePendingRequestsBeforeResubmit(orderCurrentActivity);

            String function_id = "104300001";
            int pOULen = orderRequest.OrderData.Customer.ParentOU@length;
            boolean isSkipped = true;

            for(int iPOU=0; iPOU < pOULen; iPOU++) {
                String pOURefId = orderRequest.OrderData.Customer.ParentOU[iPOU].RefId;
                String sXML = GetXMLForOU(orderRequest, pOURefId);
                String chkRes = (PreExecCheck.length > 0) ? XPath.execute(...) : "true";

                if(chkRes == "true") {
                    // Scan Agreement.Offers for eligible FUP offers
                    String fupElement = "";
                    for(int iOffer=0; iOffer < offerLen; iOffer++) {
                        specialOfferInd = evalAsString("ExtendedInfo[Name='SPECIAL_OFFER_INDICATOR']/Value");
                        fe_or_ccbs     = evalAsString("ExtendedInfo[Name='FE_OR_CCBS']/Value");
                        if(specialOfferInd.length > 0 && fe_or_ccbs == "FE"
                           && BRMS.AnyIn(FUPCreateGroupOfferInd, specialOfferInd))
                            fupElement += (empty ? "" : ",") + OfferName;
                    }
                    if(fupElement == "")
                        throw Exception.newException("OMX_DATA_ERROR", ...);

                    /* Build POU event — see §9.8 Variant ①
                       Output: JMS headers + payload/ns:doServiceRequest/ns:req
                       function_id=104300001, params: fupID, bc, company, fupElement, service_no */
                    Events... reqEvent = Event.createEvent("xslt://...");
                    Event.Ext.sendEventImmediate(reqEvent);
                    if(!isActResub) orderCurrentActivity.RequestCount++;
                    /* Audit via Event.sendEvent */
                    isSkipped = false;
                }

                // COU loop — same pattern with currCOU, GetXMLForChildOU, COU event variant
                for(int iCOU=0; iCOU < cOULen; iCOU++) { ... }
            }

            if(!isSkipped) {
                orderCurrentActivity.Status = GetActivityStatusString("1", false);
                SendDataToDB(orderRequest);
            } else
                SkipActivity(orderRequest, orderCurrentActivity, "4");
        }
        catch (Exception ae) { HandleActivityException(orderRequest, orderCurrentActivity, ae, ""); }
    }
}
