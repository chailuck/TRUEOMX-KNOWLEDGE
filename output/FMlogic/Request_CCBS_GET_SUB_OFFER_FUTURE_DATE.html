Request_CCBS_GET_SUB_OFFER_FUTURE_DATE

Retrieves future effective and expiration dates for subscriber offers from CCBS, then writes them back to SubscriberOffers in working memory.
Activity: CCBS_GET_SUB_OFFER_FUTURE_DATE Backend: CCBS Pattern: Fire-and-Forget (RequestCount++) Scope: Subscriber Generated: 2026-09-23
§1 — Overview & Purpose

Queries CCBS for the getFutureRequestOfferDate for each subscriber. The response contains a list of UpdateService entries (Soc, OfferInstanceId, EffectiveDate, ExpirationDate). The response handler writes these dates back to matching SubscriberOffers in working memory — only if the existing EffectiveDate or ExpirationDate is empty.

Uses fire-and-forget pattern (Event.Ext.sendEventImmediate + RequestCount++). Audit logging is gated by AllowWriteLog. Response always returns "true" (no RequestCount fan-in check).

§5 — Execution Flow
  1. Evaluate PreExecCheck (if set) per subscriber via GetXMLForSubscriber
  2. For passing subscribers: check if already successfully responded (skip if reqSuccess=true)
  3. Build and send CCBS_GET_SUB_OFFER_FUTURE_DATE event via Event.Ext.sendEventImmediate
  4. If not resubmit: RequestCount++
  5. If AllowWriteLog: fire audit logger event
  6. Repeat for ChildOU subscribers (using GetXMLForSubscriberInChildOU)
  7. Call SendDataToDB(orderRequest)
  8. If not skipped: set status IN_PROGRESS; else: SkipActivity("4")
