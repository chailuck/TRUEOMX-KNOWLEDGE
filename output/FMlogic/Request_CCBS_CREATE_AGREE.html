Request_CCBS_CREATE_AGREE

CCBS — Create Agreement on ParentOU and ChildOU, Retrieve CCBS AgreementNo
Backend: CCBS Pattern: assertEvent + IntraActivitySequencing (per Agreement) Priority: 5 Author: awalia-t420 Generated: 2026-09-21
§1 — Overview & Purpose

CCBS_CREATE_AGREE creates agreements on both ParentOU and ChildOU hierarchies. Covers two iteration paths: POU loop (if POU.Agreement != null) and ChildOU loop (if ChildOU.Agreement != null). CCBS returns a new AgreementNo which is written back to Agreement.AgreementId.

Bug — ChildOU audit log AUDIT_TRACE: Uses "Request Sent for CES_CREATE_AGREE" (typo: "CES" instead of "CCBS"). POU audit log is correct.
reqSuccess correlation mismatch: For POU, reqSuccess checks Response[ReferenceId == pOURefId] but the event sends RefID = Agreement.RefId. If POU.RefId ≠ Agreement.RefId, the resubmit skip logic will fail to detect a successful prior response.
agreementType source: POU path: AGREEMENT_TYPE ExtendedInfo if present, else Agreement.AgreementType. ChildOU path: always Agreement.AgreementType (no ExtendedInfo check).
