Request_CCBS_SHARE_PLAN_ADD_DISCOUNT_MAIN

Adds SharePlan discount offers (ServiceType=68, FE_OR_CCBS=FE) to the SharePlan main subscriber in CCBS via UpdateSubscriber

Priority: 5Target: CCBS Event: CCBS_UPDATE_SUBSCRIBERScope: ParentOU only Gate: SHAREPLAN_MAIN_ID required
§1 — Overview & Purpose
CCBS_SHARE_PLAN_ADD_DISCOUNT_MAIN adds discount SOC offers (ServiceType=68 with FE_OR_CCBS=FE) to the SharePlan main subscriber in CCBS. Uses the CCBS_UPDATE_SUBSCRIBER event (not the search event). Gated on subscriber having ExtendedInfo[SHAREPLAN_MAIN_ID] present (the CCBS ID of the main subscriber). Includes a GetSequenceValueRequest to obtain SOC sequence numbers.
