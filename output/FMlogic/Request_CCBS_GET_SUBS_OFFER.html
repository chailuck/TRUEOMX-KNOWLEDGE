🔍 1. Overview & Purpose
This rule sends GetSubscriberInfo queries to CCBS for every subscriber in the customer's organisational hierarchy. It iterates over both ParentOU.Subscriber[] and ChildOU.Subscriber[] arrays and dispatches one CCBS_GET_SUBS_INFO JMS event per subscriber whose offer information has not yet been successfully retrieved. The operation is the first step in enriching the order with subscriber-level offer data before downstream activation activities can proceed.

This rule fires when the process flow pointer reaches activity CCBS_GET_SUBS_OFFER and that activity's status is WAITING. It features a built-in idempotency guard: before dispatching a request for each subscriber, it checks whether a successful response (CompletionStatus == 2) already exists in the activity's Response array for that subscriber's RefId. This prevents duplicate queries on resubmission.

A configurable PreExecCheck XPath expression can exclude individual subscribers. If no subscribers require querying (all already have successful responses or all are filtered), the activity is automatically SKIPPED.

Rule type: READ / QUERY. This is a data-enrichment rule — it retrieves current subscriber offer state from CCBS. It does not modify CCBS data. The response is handled by a corresponding Response_CCBS_GET_SUBS_OFFER rule that populates orderCurrentActivity.Response[] with the returned offer data.

❓ 4. Rule Conditions (WHEN)

All four conditions must be satisfied simultaneously. The engine joins orderCurrentActivity and orderRequest via the extId/NextActivityName match.

orderCurrentActivity@extId == orderRequest.ProcessFlow.NextActivityName
orderCurrentActivity.ActivityID == "CCBS_GET_SUBS_OFFER"
orderRequest.ProcessFlow.NextActivityID == "CCBS_GET_SUBS_OFFER"
orderCurrentActivity.Status == "WAITING"

🔄 5. Execution Flow Diagram
1
Guard & Resubmit Flag
Compute isActResub = (RequestCount > 0 && IsOrderResubmitted). Fetch nextAct and cache its PreExecCheck in chkXPath. Initialise isSkipped = true.
2
ParentOU.Subscriber Loop
For each ParentOU[p].Subscriber[ps]:
• Check Response array — if ReferenceId == pSubRefId and CompletionStatus == 2 already exists → reqSuccess = true → skip this subscriber
• Evaluate PreExecCheck XPath via GetXMLForSubscriber(orderRequest, pSubRefId) — skip if result != "true"
• Build and send CCBS_GET_SUBS_INFO event; set isSkipped = false; increment RequestCount if not resubmit; emit audit log
3
ChildOU.Subscriber Loop
For each ParentOU[p].ChildOU[c].Subscriber[cs]:
• Same response-check and PreExecCheck logic as ParentOU path
• PreExecCheck uses GetXMLForSubscriberInChildOU(orderRequest, cSubRefId, pOuRefId)
• Build and send CCBS_GET_SUBS_INFO event; same counter/log pattern
4a
isSkipped = false → IN_PROGRESS
At least one event dispatched. Set orderCurrentActivity.Status = "IN_PROGRESS" via GetActivityStatusString("1", false). Call SendDataToDB to persist state.
4b
isSkipped = true → SKIPPED
No events dispatched (all subscribers already successful or filtered). Call SkipActivity(orderRequest, orderCurrentActivity, "4") → status SKIPPED, flow advances.
5
Exception Handler
Any exception → HandleActivityException: sets activity ERROR, order FAILED, fires error Logger event, persists to DB.
Key difference from write-type rules: The per-subscriber response check (Step 2/3 bullet 1) means this rule naturally handles partial-completion resubmission — only subscribers without a successful prior response will receive a new query, regardless of the isActResub flag.
▶ 6. Rule Action (THEN) — Step-by-Step Logic
1
Resubmit flag: isActResub = (orderCurrentActivity.RequestCount > 0 && orderRequest.IsOrderResubmitted)
2
Fetch nextAct & PreExecCheck: Instance.getByExtIdByUri(orderRequest.ProcessFlow.NextActivityName, "/Concepts/OM/ProcessConfig/Activity"). Cache chkXPath = nextAct.PreExecCheck. Set isSkipped = true.
3
ParentOU outer loop — for p in 0..pOuLen: capture pOuId, pOuRefId.
ParentOU Subscriber inner loop — for ps in 0..pSubLen:
  a) Response check: scan orderCurrentActivity.Response[]; if entry with ReferenceId == pSubRefId and CompletionStatus == 2 found → reqSuccess = true → skip
  b) PreExecCheck: if chkXPath.length > 0: sXML = GetXMLForSubscriber(orderRequest, pSubRefId); evaluate; skip if != "true"
  c) Create & send event: XSLT builds CCBS_GET_SUBS_INFO event with psub.SubscriberId as payload; Event.Ext.sendEventImmediate(reqEvent)
  d) Set isSkipped = false; if not resubmit: orderCurrentActivity.RequestCount++
  e) Emit audit Logger event
4
ChildOU outer loop — for c in 0..cOuLen: capture cOuId, cOuRefId.
ChildOU Subscriber inner loop — for cs in 0..cSubLen:
  a) Same response check using cSubRefId
  b) PreExecCheck: sXML = GetXMLForSubscriberInChildOU(orderRequest, cSubRefId, pOuRefId); evaluate
  c) Create & send event with csub.SubscriberId; same counter/log pattern
5
Post-loop decision:
  • !isSkipped → orderCurrentActivity.Status = GetActivityStatusString("1", false); SendDataToDB(orderRequest)
  • isSkipped → SkipActivity(orderRequest, orderCurrentActivity, "4")
!
catch(Exception ae): HandleActivityException(orderRequest, orderCurrentActivity, ae, "")

⚠ 13. Exception / Error Handling

A single top-level try/catch wraps all logic. Any exception routes to:

Risk: The outer try/catch covers all subscriber iterations. A failure partway through the ParentOU subscriber loop (e.g., at subscriber 3 of 5) will abort the remaining subscribers. Events already dispatched before the exception will not be cancelled. This may cause partial CCBS queries with no response tracking for the un-queried subscribers.

🛠 17. Migration Notes & Recommendations
Functional Requirements
IDRequirement
R1The replacement service MUST query CCBS for every subscriber across both the ParentOU and all ChildOU arrays, processing ParentOU subscribers before ChildOU subscribers.
R2Before dispatching a query for any subscriber, the service MUST check whether a successful response (CompletionStatus == 2) already exists for that subscriber's RefId — if so, skip that subscriber.
R3The correlation key for CCBS responses MUST be OMXTrackingId (not the order's concept extId). Verify end-to-end that the response routing uses the same field.
R4A configurable per-subscriber PreExecCheck XPath filter MUST be applied before each dispatch; the filter context XML MUST be scoped correctly to the subscriber (ParentOU vs ChildOU context).
R5Each dispatched query MUST include the subscriber's SubscriberId as subscrNumber in the GetSubscriberInfoRequest payload.
R6RequestCount MUST be incremented per dispatched event, but only on non-resubmit paths, to maintain idempotency tracking.
R7When no subscribers require querying, the activity MUST be marked SKIPPED and the flow MUST advance automatically.
R8Credential fields (UserName/PassWord) MUST be gated by the IsEnableUserPass configuration and MUST NOT be included when the flag is false or absent.
R9An audit log record MUST be emitted after each successful dispatch, including ESBUUID (from OMXTrackingId), operation name, and optionally the full payload.
Design Risks
RiskSeverityMitigation
JMSCorrelationID uses OMXTrackingId instead of orderRequest.@extId — inconsistent with most other FM request rules HIGH Verify that the CCBS FM server and the corresponding Response rule both use OMXTrackingId for routing/correlation. Document as a deliberate design choice. Risk: if CCBS echoes back the JMS correlation header and the response rule matches on @extId, responses will be orphaned.
Single try/catch across all subscriber iterations — partial failure mid-loop leaves earlier dispatched events untracked MEDIUM In modern architecture, move to per-subscriber error isolation with per-subscriber retry. Track dispatched vs. responded counts explicitly.
Linear O(N×M) response scan: for each of N subscribers, scans all M entries in Response[] — worst case O(N×M) MEDIUM For large OU hierarchies with many subscribers and many responses, this inner loop is O(N×M). Replace with a map/set lookup keyed on ReferenceId in the target platform.
pOuId and cOuId / cOuRefId are captured in local variables but never used in the XSLT payload or PreExecCheck functions LOW Dead variable assignments. Remove in migration to reduce code noise. Verify they were not originally intended to be passed somewhere (e.g., to the XML serialisation helpers).
Inline XSLT not independently testable or versioned MEDIUM Extract to named XSLT transform or a mapper function in the target platform for independent unit testing and version control.
No null-check on psub.SubscriberId / csub.SubscriberId before building payload LOW A subscriber with a null SubscriberId will produce an empty ns11:subscrNumber element, which CCBS will likely reject. Add validation in the replacement service.
Event type mismatch: rule is named CCBS_GET_SUBS_OFFER but sends event CCBS_GET_SUBS_INFO MEDIUM The activity ID and rule name suggest an offer query; the actual CCBS operation is GetSubscriberInfoRequest which retrieves general subscriber info (including current offers). Document the mapping clearly to avoid confusion during migration. The response rule presumably filters for offer data from the fuller subscriber info response.

/**
 * @description
 * @author DESKTOP-995HR2V

rule Rules.OMConsumers.OMXFM.Request.Request_CCBS_GET_SUBS_OFFER {
    attribute {
        priority = 5;
        forwardChain = true;
    }
    declare {
        Concepts.OrderRequest.OrderRequest orderRequest;
        Concepts.OM.ProcessConfig.Activity orderCurrentActivity;
    }
    when {
        orderCurrentActivity@extId == orderRequest.ProcessFlow.NextActivityName;
        orderCurrentActivity.ActivityID == "CCBS_GET_SUBS_OFFER";
        orderRequest.ProcessFlow.NextActivityID == "CCBS_GET_SUBS_OFFER";
        orderCurrentActivity.Status == "WAITING";
    }
    then {
        boolean isActResub = (orderCurrentActivity.RequestCount > 0 && orderRequest.IsOrderResubmitted);

        try {
            Concepts.OM.ProcessConfig.Activity nextAct = Instance.getByExtIdByUri(
                orderRequest.ProcessFlow.NextActivityName, "/Concepts/OM/ProcessConfig/Activity");
            String chkXPath = nextAct.PreExecCheck;
            boolean isSkipped = true;

            /*** Begin ParentOU ***/
            int pOuLen = orderRequest.OrderData.Customer.ParentOU@length;
            for (int p = 0; p < pOuLen; p++) {
                String pOuId = orderRequest.OrderData.Customer.ParentOU[p].OUId;
                String pOuRefId = orderRequest.OrderData.Customer.ParentOU[p].RefId;

                /*** Begin ParentOU Subscriber ***/
                int pSubLen = orderRequest.OrderData.Customer.ParentOU[p].Subscriber@length;
                for (int ps = 0; ps < pSubLen; ps++) {
                    Concepts.OrderRequest.OrderElements.Subscriber psub =
                        orderRequest.OrderData.Customer.ParentOU[p].Subscriber[ps];
                    String pSubRefId = psub.RefId;

                    boolean reqSuccess = false;
                    for(int iResp = 0; iResp < orderCurrentActivity.Response@length; iResp++) {
                        if(String.equals(orderCurrentActivity.Response[iResp].ReferenceId, pSubRefId)
                            && orderCurrentActivity.Response[iResp].CompletionStatus == 2) {
                            reqSuccess = true;
                        }
                    }

                    if(!reqSuccess) {
                        String chkRes = "true";
                        if(String.length(nextAct.PreExecCheck) > 0) {
                            String sXML = RuleFunctions.Helpers.GetXMLForSubscriber(orderRequest, pSubRefId);
                            chkRes = XPath.execute("/(" + chkXPath + ")", sXML,
                                "ns0=www.tibco.com/be/ontology/Concepts/OrderRequest/OrderRequest");
                        }

                        if(String.equals(chkRes,"true")) {
                            Events.OMConsumers.OMXFM.Request.CCBS_GET_SUBS_INFO reqEvent =
                                Event.createEvent("xslt://{{/Events/OMConsumers/OMXFM/Request/CCBS_GET_SUBS_INFO}}"
                                /* ── XSLT Variant ① ParentOU — full stylesheet shown in §9.8 ──
                                   params: $orderRequest, $pSubRefId, $globalVariables, $psub
                                   output: createEvent/event/[JMSPriority,JMSCorrelationID,OrderID,
                                           RefID,UserName?,PassWord?,OrderType?,CES?,payload/
                                           ns11:GetSubscriberInfoRequest/SubscriberIdInfo/subscrNumber] */);
                            Event.Ext.sendEventImmediate(reqEvent);
                            isSkipped = false;
                            if(!isActResub) { orderCurrentActivity.RequestCount++; }
                            long pid = System.nanoTime();
                            Event.Ext.sendEventImmediate(Event.createEvent("xslt://{{/Events/OMConsumers/OMXESB/Logger}}"
                                /* Logger XSLT: ESBUUID←OMXTrackingId, PROCESS_ID←pid+"_REQ",
                                   COMPONENT_NAME←OMX_CEP, OPERATION_NAME←"CCBS_GET_SUBS_OFFER",
                                   TARGET_SYSTEM←OMX_FM, LOG_LEVEL←INFO, AUDIT_TRACE←"Request Sent...",
                                   payload←reqEvent (only if OMX_OM/WritePayload="true") */));
                        }
                    }
                } /*** End ParentOU Subscriber ***/

                /*** Begin ChildOU ***/
                int cOuLen = orderRequest.OrderData.Customer.ParentOU[p].ChildOU@length;
                for (int c = 0; c < cOuLen; c++) {
                    String cOuId = orderRequest.OrderData.Customer.ParentOU[p].ChildOU[c].OUId;
                    String cOuRefId = orderRequest.OrderData.Customer.ParentOU[p].ChildOU[c].RefId;

                    /*** Begin ChildOU Subscriber ***/
                    int cSubLen = orderRequest.OrderData.Customer.ParentOU[p].ChildOU[c].Subscriber@length;
                    for (int cs = 0; cs < cSubLen; cs++) {
                        Concepts.OrderRequest.OrderElements.Subscriber csub =
                            orderRequest.OrderData.Customer.ParentOU[p].ChildOU[c].Subscriber[cs];
                        String cSubRefId = csub.RefId;

                        boolean reqSuccess = false;
                        for(int iResp = 0; iResp < orderCurrentActivity.Response@length; iResp++) {
                            if(String.equals(orderCurrentActivity.Response[iResp].ReferenceId, cSubRefId)
                                && orderCurrentActivity.Response[iResp].CompletionStatus == 2) {
                                reqSuccess = true;
                            }
                        }

                        if(!reqSuccess) {
                            String chkRes = "true";
                            if(String.length(nextAct.PreExecCheck) > 0) {
                                String sXML = RuleFunctions.Helpers.GetXMLForSubscriberInChildOU(
                                    orderRequest, cSubRefId, pOuRefId);
                                chkRes = XPath.execute("/(" + chkXPath + ")", sXML,
                                    "ns0=www.tibco.com/be/ontology/Concepts/OrderRequest/OrderRequest");
                            }

                            if(String.equals(chkRes,"true")) {
                                Events.OMConsumers.OMXFM.Request.CCBS_GET_SUBS_INFO reqEvent =
                                    Event.createEvent("xslt://{{/Events/OMConsumers/OMXFM/Request/CCBS_GET_SUBS_INFO}}"
                                    /* ── XSLT Variant ② ChildOU — full stylesheet shown in §9.8 ──
                                       params: $orderRequest, $cSubRefId, $globalVariables, $csub
                                       identical structure to Variant ①; $csub/SubscriberId → subscrNumber */);
                                Event.Ext.sendEventImmediate(reqEvent);
                                isSkipped = false;
                                if(!isActResub) { orderCurrentActivity.RequestCount++; }
                                long pid = System.nanoTime();
                                Event.Ext.sendEventImmediate(Event.createEvent("xslt://{{/Events/OMConsumers/OMXESB/Logger}}"
                                    /* same Logger XSLT as ParentOU variant */));
                            }
                        }
                    } /*** End ChildOU Subscriber ***/
                } /*** End ChildOU ***/
            } /*** End ParentOU ***/

            if (!isSkipped) {
                orderCurrentActivity.Status = RuleFunctions.Helpers.GetActivityStatusString("1", false);
                RuleFunctions.Helpers.SendDataToDB(orderRequest);
            } else {
                RuleFunctions.Helpers.SkipActivity(orderRequest, orderCurrentActivity, "4");
            }

        } catch (Exception ae) {
            RuleFunctions.Helpers.HandleActivityException(orderRequest, orderCurrentActivity, ae, "");
        }
    }
