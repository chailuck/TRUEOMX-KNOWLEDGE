Backend: AR (Amdocs) Priority: 5 ForwardChain: true Loop: ParentOU → Subscriber → SubscriberOffers Fan-in: IntraActivitySequencing Author: malinee-sririrom Generated: 2026-09-23
§1 — Overview & Purpose

This FM rule invokes the Amdocs AR l9MultiCreateChargeLevelCredit operation to create a charge-level credit for each SubscriberOffer where BILL=Y. In the CREATE_BILL_ADJUSTMENT flow (step 3), it is the BILL=Y branch — mutually exclusive with step 4 (BL_CREATE_CHARGE for BILL=N).

The FM sends one AR credit request per SubscriberOffer, using a composite RefID = subscriberRefId + ":" + offerName to track each offer independently. It uses IntraActivitySequencing fan-in to wait for all per-offer responses before advancing.

OMX-2755 refactor: Original implementation (pre-2755, commented out) sent one request per subscriber with all offers batched. Current implementation sends one request per SubscriberOffer individually, enabling per-offer response tracking. The old code is preserved as a comment block.
CES integration: The rule contains a fully commented-out CES_L9_MULTI_CREATE_CHARGE_LEVEL_CREDIT path for when orderRequest.OrderData.CES='Y'. This path was disabled and replaced by the current AR path, but the commented code remains as documentation of the original design intent. The current live code always routes to the standard AR event type, passing CES as a header field.

§5 — Execution Flow Diagram
1
Resubmit check: If RequestCount > 0 && IsOrderResubmitted, call IntraActivitySequencing.PurgePendingRequestsBeforeResubmit.
2
Loop ParentOU → Subscriber → SubscriberOffers: For each offer, build composite refId = subscriberRefId + ":" + offerName. Extract FE_OR_CCBS filter from offer ExtendedInfo via XPath.
3
Duplicate check: Search orderCurrentActivity.Response[] for matching refId with CompletionStatus==2. Skip if already responded.
4
PreExecCheck per offer: If nextAct.PreExecCheck is set, call GetXMLForSubscriberOfferFilterWithExtendedInfo(orderRequest, subsId, subOff.OfferName, filter) and evaluate. For CREATE_BILL_ADJUSTMENT step 3: boolean(//SubscriberOffers[ExtendedInfo[Name='BILL' and Value='Y']]) — only BILL=Y offers are processed.
5
Build & assert AR request event: Creates Events.OMConsumers.OMXFM.Request.AR_L9_MULTI_CREATE_CHARGE_LEVEL_CREDIT via XSLT. Calls Event.assertEvent(reqEvent) then IntraActivitySequencing.ActionRequestEvent(reqEvent, orderCurrentActivity).
6
Audit log: Sends ESB Logger event with AUDIT_TRACE = concat("Request Sent for ", $orderCurrentActivity/ActivityID).
7
After all offers processed — fan-in init: If !isSkipped: calls IntraActivitySequencing.SendFirstRequestEvent(orderCurrentActivity), then sets Status = GetActivityStatusString("1", false) and SendDataToDB. Otherwise: SkipActivity(orderRequest, orderCurrentActivity, "4").

§18 — Full Source Code
/** @author malinee-sririrom */
rule Rules.OMConsumers.OMXFM.Request.Request_AR_L9_MULTI_CREATE_CHARGE_LEVEL_CREDIT {
  attribute { priority = 5; forwardChain = true; }
  declare {
    Concepts.OrderRequest.OrderRequest orderRequest;
    Concepts.OM.ProcessConfig.Activity orderCurrentActivity;
  }
  when {
    orderCurrentActivity@extId == orderRequest.ProcessFlow.NextActivityName;
    orderCurrentActivity.ActivityID == "AR_L9_MULTI_CREATE_CHARGE_LEVEL_CREDIT";
    orderRequest.ProcessFlow.NextActivityID == "AR_L9_MULTI_CREATE_CHARGE_LEVEL_CREDIT";
    orderCurrentActivity.Status == "WAITING";
  }
  then {
    boolean isActResub = (orderCurrentActivity.RequestCount>0 && orderRequest.IsOrderResubmitted);
    try {
      if(isActResub) IntraActivitySequencing.PurgePendingRequestsBeforeResubmit(orderCurrentActivity);
      boolean isSkipped = true;
      // Loop ParentOU → Subscriber → SubscriberOffers
      for(int i=0; i < iPOULen; i++) {
        for(int p=0; p < pSubscriberLen; p++) {
          for(int q=0; q < qSubOffLen; q++) {
            // refId = subsId + ":" + subOff.OfferName (composite key)
            // filter = XPath on subOff/ExtendedInfo[Name="FE_OR_CCBS"]/Value
            // skip if already responded (CompletionStatus==2 for refId)
            if(!reqSuccess) {
              // evaluate PreExecCheck via GetXMLForSubscriberOfferFilterWithExtendedInfo
              if(chkRes == "true") {
                /* CES path (commented out — pre OMX-2755 design) */
                Events.OMConsumers.OMXFM.Request.AR_L9_MULTI_CREATE_CHARGE_LEVEL_CREDIT reqEvent =
                  Event.createEvent("xslt://{{...}}");
                  /* XSLT builds l9MultiCreateChargeLevelCredit:
                     accountId ← Account[1], chargeId ← OfferName,
                     creditTypeOption = "auto", amount ← AMOUNT ExtendedInfo,
                     taxInclude ← OMXUtils:textToAscii(TAX_INCLUDE) — see §9.8 */
                Event.assertEvent(reqEvent);
                IntraActivitySequencing.ActionRequestEvent(reqEvent, orderCurrentActivity);
                // audit log: concat("Request Sent for ", ActivityID)
                isSkipped = false;
              }
            }
          }
        }
      }
      // start before OMX-2755 : Bill Adjustment (old per-subscriber code — commented out)
      if(!isSkipped) {
        IntraActivitySequencing.SendFirstRequestEvent(orderCurrentActivity);
        orderCurrentActivity.Status = GetActivityStatusString("1", false);
        SendDataToDB(orderRequest);
      } else {
        SkipActivity(orderRequest, orderCurrentActivity, "4");
      }
    } catch(Exception ae) {
      HandleActivityException(orderRequest, orderCurrentActivity, ae, "");
    }
  }
}
§19 — Response Message Rule

§19.1 — Overview

Receives AR credit response per SubscriberOffer. Extracts per-offer result fields (creditId, completeIndicator, creditNoteNumber, errorMessage) and writes them back as ExtendedInfo on the matching offer. Uses IntraActivitySequencing for fan-in completion.

RefId decomposition: refId = String.split(eventResponse.RefID, ":")[0] → strips offerName to get subscriber RefId for lookup.
