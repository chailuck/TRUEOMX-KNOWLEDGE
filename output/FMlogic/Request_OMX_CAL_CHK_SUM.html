Request_OMX_CAL_CHK_SUM

Computes Luhn checksum for ICC_ID and writes ICC_ID_CHG_SUM ExtendedInfo on Subscriber/Offer

Activity: OMX_CAL_CHK_SUM Backend: OMX Internal No Outbound Call Generated: 2026-09-23
§1 — Overview & Purpose

A local computation rule with no outbound ESB/JMS call. It iterates every Subscriber and their SubscriberOffers, locates ICC_ID (SIM card ICCID), computes a Luhn checksum digit(s) using RuleFunctions.Helpers.Luhn(iccId), then writes a new ICC_ID_CHG_SUM ExtendedInfo on the subscriber or offer for downstream eSIM provisioning (SMDP+).

Two ICC_ID source paths:

  • RIO_SWAP path (PROJ=RIO_SWAP or subscriber.ExtendedInfo[ICC_ID] present): reads ICC_ID from subscriber-level ExtendedInfo → writes SubscriberExtendedInfo ICC_ID_CHG_SUM on the subscriber.
  • Standard path: reads ICC_ID from offer-level (psof/csof.ExtendedInfo[ICC_ID]) → writes SubscriberOffersExtendedInfo ICC_ID_CHG_SUM on the offer.

The resulting ICC_ID_CHG_SUM value is then tested by the SMDP_PLUS activity's PreExecCheck (ICC_ID_CHG_SUM present and not SMDP_COMFIRMED=Y).

§5 — Execution Flow
  1. If resubmit (RequestCount > 0 && IsOrderResubmitted): call PurgePendingRequestsBeforeResubmit
  2. Read next activity to get its PreExecCheck expression
  3. Get PROJ parameter from current activity (GetActivityParamValueFromKey)
  4. Loop ParentOU[p].Subscriber[s].SubscriberOffers[o]:
    1. Skip if offer already has CompletionStatus=2 in Response array
    2. Evaluate next-activity PreExecCheck via GetXMLForSubscriberOfferFilterWithExtendedInfo
    3. If PreExecCheck passes: check iccidInSub = subscriber has ExtendedInfo[ICC_ID]
    4. If RIO_SWAP or iccidInSub: get ICC_ID from subscriber ExtendedInfo, compute Luhn, write SubscriberExtendedInfo(ICC_ID_CHG_SUM) onto subscriber, fire audit log, set isSkipped=false, break
    5. Else: get ICC_ID from offer ExtendedInfo, compute Luhn, write SubscriberOffersExtendedInfo(ICC_ID_CHG_SUM) onto offer, fire audit log, set isSkipped=false
  5. Loop ParentOU[p].ChildOU[cou].Subscriber[cs].SubscriberOffers[o]: same logic with ChildOU variant of helper functions
  6. If not isSkipped: call NextActivity; else: call SkipActivity("4")

§9 — Computation Logic — ICC_ID_CHG_SUM Generation

Luhn checksum computation:

String iccIdCheckSum = RuleFunctions.Helpers.Luhn(iccId);
iccIdChgSum.Value = iccId + iccIdCheckSum;  // e.g. "8988...12" + "3"

ICC_ID_CHG_SUM extId pattern:

// Subscriber variant (SubscriberExtendedInfo):
extId = concat($iccId, ':ICC_ID_CHG_SUM', $psof/@extId)

// Offer variant (SubscriberOffersExtendedInfo):
extId = concat($iccId, ':ICC_ID_CHG_SUM', $psof/@extId)   // ParentOU
extId = concat($iccId, ':ICC_ID_CHG_SUM', $csof/@extId)   // ChildOU

Source-path decision logic:

ConditionICC_ID SourceWrite Target
PROJ=RIO_SWAP OR subscriber.ExtendedInfo[ICC_ID] existsSubscriber ExtendedInfo[ICC_ID]SubscriberExtendedInfo on subscriber
OtherwiseOffer ExtendedInfo[ICC_ID]SubscriberOffersExtendedInfo on offer

§17 — Migration Notes & Recommendations
#Requirement / RiskSeverity
R1Luhn algorithm implementation must match RuleFunctions.Helpers.Luhn exactly — any deviation invalidates the ICC_ID_CHG_SUM and causes SMDP+ to reject the eSIM download[HIGH]
R2RIO_SWAP path (PROJ=RIO_SWAP) reads ICC_ID from subscriber-level; standard path reads from offer-level — both must be preserved in the migration[HIGH]
R3ICC_ID_CHG_SUM is written in-memory before SMDP_PLUS runs; the downstream eSIM flow depends on this value existing on the correct object (subscriber vs offer)[MEDIUM]
R4SMDP_PLUS PreExecCheck tests for ICC_ID_CHG_SUM presence — if this rule skips (no ICC_ID), SMDP+ is also skipped; migration must preserve this gate[MEDIUM]
R5The rule evaluates the next activity's PreExecCheck to decide whether to process each offer — this cross-activity dependency must be modelled explicitly in the migration[MEDIUM]
R6SkipActivity code "4" is significant; ensure downstream orchestration handles it correctly[LOW]
§18 — Full Source Code
rule Rules.OMConsumers.OMXFM.Request.Request_OMX_CAL_CHK_SUM {
    attribute { priority = 5; forwardChain = true; }
    declare {
        Concepts.OrderRequest.OrderRequest orderRequest;
        Concepts.OM.ProcessConfig.Activity orderCurrentActivity;
    }
    when {
        orderCurrentActivity@extId == orderRequest.ProcessFlow.NextActivityName;
        orderCurrentActivity.ActivityID == "OMX_CAL_CHK_SUM";
        orderRequest.ProcessFlow.NextActivityID == "OMX_CAL_CHK_SUM";
        orderCurrentActivity.Status == "WAITING";
    }
    then {
        boolean isActResub = (orderCurrentActivity.RequestCount > 0 && orderRequest.IsOrderResubmitted);
        try {
            if(isActResub) { /* PurgePendingRequestsBeforeResubmit */ }

            Activity nextAct = Instance.getByExtIdByUri(orderRequest.ProcessFlow.NextActivityName, ...);
            String projName = "PROJ";
            String paramValue = GetActivityParamValueFromKey(orderCurrentActivity, projName);

            for (int p; p < pOuLen; p++) {
                for (int s; s < pSubLen; s++) {
                    for (int o; o < pSubOfferLen; o++) {
                        /* skip if already completed */
                        /* evaluate next-activity PreExecCheck */
                        if(chkRes == "true") {
                            boolean iccidInSub = XPath.evalAsBoolean("count($subscriber/ExtendedInfo[Name='ICC_ID'])>0");
                            if(String.equals("RIO_SWAP", paramValue) || iccidInSub) {
                                String iccId = /* ICC_ID from subscriber ExtendedInfo */;
                                if(String.length(iccId) > 0) {
                                    String iccIdCheckSum = Luhn(iccId);
                                    /* Instance.createInstance(SubscriberExtendedInfo XSLT — see §10) */
                                    iccIdChgSum.Value = iccId + iccIdCheckSum;
                                    subscriber.ExtendedInfo[...] = iccIdChgSum;
                                    /* fire Logger audit event — see §11 */
                                    isSkipped = false; break;
                                }
                            } else {
                                String iccId = /* ICC_ID from offer ExtendedInfo */;
                                if(String.length(iccId) > 0) {
                                    String iccIdCheckSum = Luhn(iccId);
                                    /* Instance.createInstance(SubscriberOffersExtendedInfo XSLT — see §10) */
                                    iccIdChgSum.Value = iccId + iccIdCheckSum;
                                    psof.ExtendedInfo[...] = iccIdChgSum;
                                    /* fire Logger audit event — see §11 */
                                }
                            }
                            isSkipped = false;
                        }
                    }
                }
                /* ChildOU loop: same pattern with GetXMLForSubscriberOfferInChildOU... */
            }

            if(!isSkipped) { NextActivity(orderRequest, orderCurrentActivity); }
            else           { SkipActivity(orderRequest, orderCurrentActivity, "4"); }

        } catch (Exception ae) {
            HandleActivityException(orderRequest, orderCurrentActivity, ae, "");
        }
    }
}
