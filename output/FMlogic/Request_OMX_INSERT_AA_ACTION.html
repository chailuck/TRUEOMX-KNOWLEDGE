Request_OMX_INSERT_AA_ACTION

Internal OMX enrichment — pre-populates subscriber ExtendedInfo fields for AA SMS notification before AA provisioning step.
Activity: OMX_INSERT_AA_ACTION Type: OMX Internal Enrichment No External Backend Scope: ChildOU Subscriber (primary) Generated: 2026-09-23
§1 — Overview & Purpose

Pre-populates subscriber ExtendedInfo fields needed for AA SMS action notification. No external backend call is made directly by this rule — it enriches working memory so downstream AA steps can access structured data. The activity parameter specifies the action type (e.g., SMS).

Key data computed: price plan name, SOC description (language-aware TH/EN), contract offer name, action type, SMS indicator, cycle count, and PP effective/expiration dates.

Note: The rule file is unusually large (303KB) due to many inline XSLT create-instance calls. The response rulefunction uses IsAllResponseSuccess(currActivity) for completion.

§5 — Execution Flow
  1. Check PreExecCheck at order level (not per-subscriber)
  2. If check passes: iterate ChildOU subscribers
  3. Per-subscriber PreExecCheck (optional)
  4. For passing subscribers, create and append ExtendedInfo entries:
    • PP ← SubscriberOffers[ServiceType=80]/OfferName
    • SOC_PROP ← language-aware SOC description (TH: BILL_DESCRIPTION, then thai_offer_description, else description; EN: english_offer_description, else description)
    • CONTRACT ← SubscriberOffers[ServiceType=85][SocProperties contains 'TR_CONTRACT_IND=Y']/OfferName, or '-'
    • ACTION ← activity parameter (e.g., "SMS")
    • SMS_IND ← SubscriberOffers[FE_OR_CCBS='FE' or 'BRMS']/ExtendedInfo[SMS_IND]/Value
    • CYCLE_COUNT ← SubscriberOffers[FE_OR_CCBS='BRMS']/ExtendedInfo[CYCLE_COUNT]/Value
  5. Calculate PP duration: GetPPDurationMonth(socProps, propoSocProps)
  6. Get billing cycle: GetBillCycle(orderRequest)
  7. Calculate PP effective date: DateTime.format(now, "dd-MMM-yyyy")
  8. Calculate PP expiration date: GetPPExpirationDate(effDate, format, durationMn, billCycle, -1)
  9. If language=TH: convert month names to Thai via ConvertMntoThaiMn
  10. Create and append: EFFECT_DATE, EXPIRE_DATE ExtendedInfo
  11. Set activity status and complete
