Request_CCBS_CREATE_CUST_WITH_CYCLE

CCBS — Create New Customer Record with Billing Cycle
Backend: CCBS Pattern: sendEventImmediate (single) Priority: 5 Author: RS33-BANDIT Generated: 2026-09-21
§1 — Overview & Purpose

CCBS_CREATE_CUST_WITH_CYCLE creates a new customer record in CCBS, including identity, name (CORP or INDY), address, billing cycle, and general customer info. The response writes the new CCBS-assigned CustomerNo back to Customer.CustomerId and also populates BirthDate, Identification, CustomerTypeInfo, and (for qualifying order types) full name and address from the CCBS record.

LogicalDate concept: The activity date falls back through 4 levels — OPEN_DATE ExtendedInfo → EffectiveDate → LogicalDate concept → current date.
Audit log mismatch: Response audit log uses OPERATION_NAME = "CCBS_CREATE_CUSTOMER_WITH_CYCLE" (with underscores before CYCLE), while the ActivityID is "CCBS_CREATE_CUST_WITH_CYCLE". Migration must align these names.
