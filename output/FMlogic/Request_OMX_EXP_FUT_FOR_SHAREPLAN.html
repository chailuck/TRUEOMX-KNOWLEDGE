OMX internal — expires/processes future orders for SharePlan; reads OMX_SEARCH_FUT_ALL response and handles future-dated SOC changes

§1 — Overview & Purpose
OMX_EXP_FUT_FOR_SHAREPLAN processes future-dated order records for subscribers in an APPLY_SHARE_PLAN flow. It reads the pre-computed response from OMX_SEARCH_FUT_ALL (activity extId processFlow:OMX_SEARCH_FUT_ALL) and processes FutureOrdersWithSoc entries. Uses the LogicalDate concept for date comparisons. The Parameter[1] provides a status update value (format "key=value", parses after "=").

§5 — Execution Flow
  1. Read LogicalDate concept; fall back to DateTime.now() if blank
  2. Parse status_update from Parameter[1] (substring-after "="); default "4" if no parameter
  3. Iterate ParentOU → Subscriber; check response already received
  4. Evaluate PreExecCheck per subscriber
  5. Locate OMX_SEARCH_FUT_ALL activity response by extId (processFlow@extId + ":OMX_SEARCH_FUT_ALL")
  6. Iterate FutureOrdersWithSoc entries; apply date-based filtering against LogicalDate
  7. Process qualifying future orders (expire or update status)
  8. Set activity status "1"; persist
