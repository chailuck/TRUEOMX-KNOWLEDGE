CVSS — Get Maximum Allowed Only Subscribers
Backend: CVSS Pattern: sendEventImmediate (single) Priority: 5 Author: awalia-t420 Generated: 2026-09-21
§1 — Overview & Purpose

CVSS_GET_MAX_ALLOW_ONLY_SUB queries CVSS for the maximum number of allowed-only subscribers for a given customer, based on their Thai ID, customer category type, and company code. Used during ACTIVATION to enforce subscriber count limits for prepaid or specific subscriber types.

The response populates MAX_ALLOW_ONLY_SUB into both the Subscriber's ExtendedInfo and Customer.ExtendedInfo, enabling downstream rules to compare existing subscriber counts against the allowed maximum.

Channel mapping: if OrderData.Channel='EOC' → 'SHOP'; if DealerCode starts with '8' → 'SHOP'; otherwise → 'DEALER'.

  2. Extract local vars: thaiId = Identification; refId = Customer.CustomerId
