Request_NAS_CHECK_COLLECTION_BLACKLIST

Checks the NAS collection blacklist for a subscriber's ID number. Writes RELAX_STATUS back to subscriber ExtendedInfo from the response.
Activity: NAS_CHECK_COLLECTION_BLACKLIST Backend: NAS Pattern: IntraActivitySequencing Scope: Subscriber (ChildOU primary, then ParentOU) Generated: 2026-09-23
§1 — Overview & Purpose

Invokes the NAS CheckCollectionBlacklist API using the customer's identification number (CustomerGeneralInfo/Identification) and a hardcoded company code "AL". The response's relaxStatus is written back to each matched subscriber's ExtendedInfo as the key RELAX_STATUS.

Iteration order: ChildOU subscribers first, then ParentOU subscribers. Uses IntraActivitySequencing pattern. Old RequestCount fan-in code is commented out.

§5 — Execution Flow
  1. If resubmit: call PurgePendingRequestsBeforeResubmit
  2. ChildOU first: Iterate ParentOU[i].ChildOU[k].Subscriber[j]
  3. Evaluate PreExecCheck via GetXMLForSubscriberInChildOU
  4. For passing: fire NAS_CHECK_COLLECTION_BLACKLIST via IntraActivitySequencing
  5. Fire audit logger
  6. Then ParentOU: Iterate ParentOU[i].Subscriber[j]
  7. Evaluate PreExecCheck via GetXMLForSubscriber
  8. For passing: fire request via IntraActivitySequencing
  9. Fire audit logger
  10. If not skipped: SendFirstRequestEvent + set IN_PROGRESS; else: SkipActivity("4")
