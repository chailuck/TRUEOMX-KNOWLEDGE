Request_CCBS_UPDATE_BILLING_ARRANGEMENT

Updates billing arrangement for an account — sets L3BillFormat, L9BillLang, and L9SplitParam based on order type and cancel type.

Backend: CCBS Pattern: IntraActivitySequencing Scope: Account-level Priority: 5 Used in: CHANGE_ACCOUNT_BILLING_INFO
§1Overview & Purpose

This rule sends an UpdateBillingArrangement request to CCBS for each account in the order. It sets bill format (L3BillFormat), bill language (L9BillLang), and L9 split parameter (L9SplitParam) on the account's billing arrangement. The L9SplitParam logic is complex: it varies by whether the order is an L9 Resume order (OrderType=11), whether an activity-level L9SPLITPARAM parameter overrides it, and the CANCEL_TYPE ExtendedInfo key.

Key behavioural notes:
• FINAL_BILL=N in OrderData ExtendedInfo forces L3BillFormat="PS" (paper statement) regardless of account data.
• OrderType "11" (POSTPAID_L9_RESUME) triggers a special L9SplitParam lookup from account ExtendedInfo.
• ALT_CES activity parameter allows overriding the CES routing target.

§5Execution Flow
  1. Load logicalDateRes and logicalDateVal from working memory (loaded but not used in XSLT)
  2. Load nextAct (current activity concept) via Instance.getByExtIdByUri
  3. Read activity parameters: ALT_CES and L9SPLITPARAM
  4. If RequestCount > 0 && IsOrderResubmitted → call PurgePendingRequestsBeforeResubmit
  5. Detect OrderType=11 (POSTPAID_L9_RESUME) → set isL9ResumeOrder="true"
  6. Iterate Customer.Account[i] array; evaluate PreExecCheck via GetXMLForAccount
  7. For each account passing PreExecCheck: build and Event.assertEvent(reqEvent)
  8. Call IntraActivitySequencing.ActionRequestEvent(reqEvent, orderCurrentActivity)
  9. Set isSkipped = false
  10. After loop: if not skipped → IntraActivitySequencing.SendFirstRequestEvent + set status IN_PROGRESS; else → SkipActivity
§7L9SplitParam Decision Logic
L9SplitParam controls how CCBS splits final bill charges. Three-way branching based on isL9ResumeOrder, activity parameter, and order data:
ConditionL9SplitParam Value
isL9ResumeOrder != "true" AND CANCEL_TYPE = 'endbill'"FFGB" (hardcoded)
isL9ResumeOrder != "true" AND other CANCEL_TYPE"SIFN" (hardcoded)
string-length($l9splitparam) > 0 (L9SPLITPARAM activity param)Value from L9SPLITPARAM parameter
isL9ResumeOrder = "true" AND account ExtendedInfo L9SplitParam = 'SIFN'"CLEAR" (resets split)
isL9ResumeOrder = "true" AND other L9SplitParam$account/ExtendedInfo[Name="L9SplitParam"]/Value

The xsl:choose in the XSLT evaluates the first matching branch in order. The string-length($l9splitparam)>0 branch is second — it can only fire if isL9ResumeOrder != "true" already failed (i.e., if isL9ResumeOrder IS "true" but the first when didn't match).

§9.8 XSLT Stylesheet Source

<xsl:stylesheet xmlns:ns1="amdocs.csm3g.datatypes.UpdateBillingArrangementRequest.xsd"
    xmlns:ns2="amdocs.csm3g.datatypes.ActivityInfo"
    xmlns:ns3="amdocs.csm3g.datatypes.BillingArrangementIdInfo"
    xmlns:ns4="amdocs.csm3g.datatypes.BillingArrangementBillInfo"
    version="1.0">
  <xsl:param name="orderRequest"/>   <!-- full order -->
  <xsl:param name="globalVariables"/>
  <xsl:param name="altParam"/>         <!-- "Y" if ALT_CES param set -->
  <xsl:param name="account"/>          <!-- current Account element -->
  <xsl:param name="isL9ResumeOrder"/>  <!-- "true" if OrderType=11 -->
  <xsl:param name="l9splitparam"/>    <!-- L9SPLITPARAM activity param override -->

  <xsl:template match="/">
    <createEvent><event>
      <!-- Headers -->
      <JMSPriority>$orderRequest/OrderPriority</JMSPriority>
      <JMSCorrelationID>$orderRequest/OrderData/OMXTrackingId</JMSCorrelationID>
      <OrderID>$orderRequest/OrderData/OrderID</OrderID>
      <!-- Credential gate -->
      <xsl:if test="IsEnableUserPass='true'">
        <UserName>...</UserName>  <PassWord>...</PassWord>
      </xsl:if>
      <xsl:if test="$orderRequest/OrderData/OrderType">
        <OrderType>...</OrderType>
      </xsl:if>
      <!-- CES routing: ALT_CES override or standard -->
      <xsl:choose>
        <xsl:when test="$altParam='Y' and ExtendedInfo[Name='ALT_CES']/Value != ''">
          <CES>$ExtendedInfo[Name='ALT_CES']/Value</CES>
        </xsl:when>
        <xsl:otherwise>
          <xsl:if test="$orderRequest/OrderData/CES">
            <CES>$orderRequest/OrderData/CES</CES>
          </xsl:if>
        </xsl:otherwise>
      </xsl:choose>
      <!-- Payload -->
      <payload>
        <ns1:UpdateBillingArrangementRequest>
          <ns3:BillingArrangementIdInfo>
            <!-- Prefer BillingArrangementId; fallback to AccountID -->
            <xsl:choose>
              <xsl:when test="exists($account/BillingArrangementId) and $account/BillingArrangementId > 0">
                <ns3:BillingArrangementId>$account/BillingArrangementId</ns3:BillingArrangementId>
              </xsl:when>
              <xsl:otherwise>
                <xsl:if test="$account/AccountID">
                  <ns3:BillingArrangementId>$account/AccountID</ns3:BillingArrangementId>
                </xsl:if>
              </xsl:otherwise>
            </xsl:choose>
          </ns3:BillingArrangementIdInfo>
          <ns4:BillingArrangementBillInfo>
            <!-- L3BillFormat: FINAL_BILL=N → "PS"; else BillFormat -->
            <xsl:choose>
              <xsl:when test="ExtendedInfo[Name='FINAL_BILL']/Value='N'">
                <ns4:L3BillFormat>PS</ns4:L3BillFormat>
              </xsl:when>
              <xsl:otherwise>
                <xsl:if test="$account/BillingArrangementBillInfo/BillFormat">
                  <ns4:L3BillFormat>$BillFormat</ns4:L3BillFormat>
                </xsl:if>
              </xsl:otherwise>
            </xsl:choose>
            <xsl:if test="$account/BillingArrangementBillInfo/BillLanguage">
              <ns4:L9BillLang>$BillLanguage</ns4:L9BillLang>
            </xsl:if>
            <!-- L9SplitParam 3-way logic (see §7) -->
            <xsl:choose>
              <xsl:when test="$isL9ResumeOrder != 'true'">
                <!-- CANCEL_TYPE=endbill → FFGB; else SIFN -->
              </xsl:when>
              <xsl:when test="string-length($l9splitparam) > 0">
                <ns4:L9SplitParam>$l9splitparam</ns4:L9SplitParam>
              </xsl:when>
              <xsl:when test="$isL9ResumeOrder = 'true'">
                <!-- SIFN → CLEAR; else account ExtendedInfo[L9SplitParam] -->
              </xsl:when>
            </xsl:choose>
          </ns4:BillingArrangementBillInfo>
          <ns2:ActivityInfo>
            <!-- ActivityReason: AccountActivityInfo or "CREQ" default -->
            <ns2:ActivityReason>if(ActivityReason exists) else "CREQ"</ns2:ActivityReason>
            <xsl:if test="$account/AccountActivityInfo/UserText">
              <ns2:UserText>...</ns2:UserText>
            </xsl:if>
          </ns2:ActivityInfo>
        </ns1:UpdateBillingArrangementRequest>
      </payload>
    </event></createEvent>
  </xsl:template>
</xsl:stylesheet>
