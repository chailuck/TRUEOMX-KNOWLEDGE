Request_TDG_RESUME_SUBSCRIBER

Resume a TDG (TRUE Digital) subscriber — iterates MaterialInfo per subscriber, sends ResumeSubscriberRequest with reason RC (CCBS) or RR (non-CCBS)

Priority: 5 ForwardChain: true Target: TDG (TRUE Digital) Event: TDG_RESUME_SUBSCRIBER Fan-in: RequestCount == successResponseCount Used in RESTORE: Step 39
§1 — Overview & Purpose

This FM resumes a TDG (TRUE Digital) subscriber by sending a ResumeSubscriberRequest for each Material item in the subscriber's MaterialInfo.Material[] array. It is used during the RESTORE process for subscribers with TR_SPECIAL_OFFER_IND=IOTBU (IoT Bundle subscribers on TDG).


RefID construction: SubRefId + ":" + material.MatCode (or MatSerial if MatCode is blank) — per-material granularity.


Logger OPERATION_NAME anomaly: Both ParentOU and ChildOU variants use "TDG_CREATE_SUBSCRIBER" in the audit logger — not "TDG_RESUME_SUBSCRIBER". This is a copy-paste naming error.

reason field: Channel="CCBS" → reason="RC"; all other channels → reason="RR". This is a 2-way xsl:choose.

§6 — Rule Action (THEN) — Key Details

Material-level fan-out

Unlike most FMs that iterate Subscribers, this FM iterates Material items within each Subscriber's MaterialInfo. Each material gets its own TDG request. RefID = SubRefId:MatCode (or SubRefId:MatSerial).


reason field (2-way choose)

ConditionreasonMeaning
OrderData.Channel = 'CCBS'"RC"Resume — Collection
Otherwise"RR"Resume — Regular

propositioncode lookup

Finds the offer with ServiceType="85" AND SocProperties contains 'TR_CONTRACT_IND=Y' in RelatedOffersArray and uses its OfferName. This is a XPath expression in the XSLT template.


extId on event

The TDG_RESUME_SUBSCRIBER event sets extId = OMXUtils:generateTrackingID() directly on the event (via xsl:attribute name="extId") — different from most FMs that do not set event extId in XSLT.
