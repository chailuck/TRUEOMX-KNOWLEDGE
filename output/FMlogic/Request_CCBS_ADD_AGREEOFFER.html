Request_CCBS_ADD_AGREEOFFER

CCBS — Add Agreement Offers to POU and ChildOU Agreements, Including Pooled Offer Instance ID Write-back
Backend: CCBS Pattern: assertEvent + IntraActivitySequencing (per Offer) Priority: 5 Author: awalia-t420 Generated: 2026-09-21
§1 — Overview & Purpose

CCBS_ADD_AGREEOFFER adds service offers to existing CCBS Agreements for both POU and ChildOU paths. Unlike other ACTIVATION FMs which send one event per OU/account, this rule sends one event per offer within each Agreement — meaning a POU with 3 qualifying offers generates 3 separate JMS requests.

Three-pass logic per POU iteration:
  1. Pass 1 (SOC deduplication): Collects unique SOCs from ALL offers (POU+ChildOU RelatedOffersArray) + their BRMS-derived GetSplOffIndForSoc values (PLG/CAP/RPD/CPD etc.) into alSOCs/alPropVal arrays.
  2. Pass 2 (POU offers): Filters POU.Agreement.Offers via PreExecCheck → sends one event per qualifying offer.
  3. Pass 3 (ChildOU offers): Same but for each ChildOU.Agreement.Offers.
Sequence number allocation: Each event requests a SOC_SEQ_NO sequence increment = count(offers) + count(offers/RelatedOffersArray) via GetSequenceValueRequest. This pre-allocates all sequence slots for the offer set in one call.
Pooled offer write-back (response): For each OfferDetail in the response where SOC is RPD/CPD (pooled), appends AgreementExtendedInfo with Name=POOLED_OFFER_INSTANCE_ID_{soc} and Value=OfferInstanceCode to the matched Agreement's ExtendedInfo.
Agreement lookup (response): Uses Instance.getByExtIdByUri("AG:"+OMXTrackingId+":"+RefID, ...) or "CAG:..." variant to locate the Agreement concept.

§19 — Response Message Rule

No per-offer field write-back to the Agreement/Offer structures (unlike CCBS_CREATE_ACCT). The response primarily performs pooled offer instance ID write-back for RPD/CPD-type SOCs.

Write TargetSourceCondition
currActivity.Response[]CCBS_AddAgreeOfferRes (ResponseCode, ResponseMsg, CompletionStatus, RefID)Always (every offer response)
agree.ExtendedInfo[]Name=POOLED_OFFER_INSTANCE_ID_{soc}, Value=OfferDetails[i].OfferInstanceCodeOnly if SOC's propValue is in sPooled (RPD or CPD)
Agreement lookup pattern: Instance.getByExtIdByUri("AG:"+OMXTrackingId+":"+RefID, ...) or "CAG:..." fallback. The "AG"/"CAG" prefix distinguishes Agreement vs Child Agreement in Working Memory.

Global variables:
  • OMX-OM/PoolingPooled/PooledPrefix (default: "POOLED_OFFER_INSTANCE_ID")
  • OMX-OM/PoolingPooled/PooledIndicator (default: "RPD,CPD")
Fan-in: IntraActivitySequencing.ActionResponseEvent(currActivity) — returns "true" when all per-offer requests answered.
