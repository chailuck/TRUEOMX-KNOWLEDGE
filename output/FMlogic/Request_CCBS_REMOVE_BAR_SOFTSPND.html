Request_CCBS_REMOVE_BAR_SOFTSPND

Remove soft-suspend SOC bar from CCBS for each subscriber — ParentOU + ChildOU loop, IntraActivitySequencing fan-in

Priority: 5 ForwardChain: true Target: CCBS Event: CCBS_REMOVE_BAR_SOFTSPND Fan-in: IntraActivitySequencing Used in RESTORE: Steps 20, 22
§1 — Overview & Purpose

This FM removes a soft-suspend barring SOC (soc=50412) from CCBS for every subscriber in the order. It is used during the RESTORE process to lift the barring that was placed when the subscriber was soft-suspended.


The rule iterates ParentOU subscribers and ChildOU subscribers. For each subscriber, it looks up the prior CCBSGetSubsInfoRes from working memory (extId = GSIR:<OMXTrackingId>:<refId>) to confirm SOC 50412 is present. If found, it builds and sends the CCBS_REMOVE_BAR_SOFTSPND event using IntraActivitySequencing fan-in.

Usage context: Called twice in RESTORE — step 20 (non-CCBS channel, subscriber soc=50412 in status 65 or 83) and step 22 (CCBS collection channel, status 85, socStatus=84).

§6 — Rule Action (THEN) — Detailed Logic

Resubmit handling

isActResub = (orderCurrentActivity.RequestCount > 0 && orderRequest.IsOrderResubmitted) — if true, pending requests are purged before re-dispatch.


SOC lookup

For each subscriber, the rule retrieves the cached CCBS subscriber info response from working memory using extId GSIR:<OMXTrackingId>:<refId>. It then runs an XPath on that concept to find Services[Soc="50412"]/Soc. If the concept is null or the SOC is missing, soc is set to "0" but the request is still sent (the XSLT emits offersToRemove only when string-length($soc)>0, so soc="0" would still be included).


IntraActivitySequencing

Uses ActionRequestEvent + SendFirstRequestEvent pattern — sequential fan-out, not parallel. The response handler uses IntraActivitySequencing.ActionResponseEvent for fan-in.


Skip condition

If no requests were sent (isSkipped == true), calls RuleFunctions.Helpers.SkipActivity(orderRequest, orderCurrentActivity, "4") to mark the activity as skipped and advance the process.

§19 — Response Message Rule: Response_CCBS_REMOVE_BAR_SOFTSPND

Parses the CCBS response, constructs a CCBSRemoveBarSoftSpndRes concept, appends to currActivity.Response[], logs audit trail, then delegates completion check to IntraActivitySequencing.ActionResponseEvent.
