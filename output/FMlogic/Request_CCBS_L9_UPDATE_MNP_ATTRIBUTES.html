§1 — Overview & Purpose

Updates MNP (Mobile Number Portability) L9 attributes in CCBS during port-out cancellation (OrderType=10). Sets DonorOperator, DonorZone, RecOperator, RecZone, and L9PortInd fields from MNPInfo data in the order request.

Used in CANCEL_SUBSCRIBER process — Step 58 — gated on OrderType=10 and not ATS path. Configurable via L9_PORT_IND (default 79) and ACTIVITY_TYPE (default C) parameters.
