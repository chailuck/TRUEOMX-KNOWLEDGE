Request_OPCDB_GET_PROPO_MAPPING

Queries OPCDB for proposition (offer) mapping — gated on subscriber having TR_CONTRACT_NUMBER parameter in an offer

Priority: 5Target: OPCDB Event: OPCDB_GET_PROPO_MAPPINGScope: ParentOU only Schema: PropositionMapping.xsd
§1 — Overview & Purpose
OPCDB_GET_PROPO_MAPPING queries OPCDB for a proposition/offer mapping. It is triggered only when the subscriber has a SubscriberOffers entry with a ParameterInfo[TR_CONTRACT_NUMBER]. It sends the subscriber's MSISDN and the offer's OfferName as "proposition" to OPCDB, using the PropositionMapping.xsd schema.

§5 — Execution Flow
  1. Iterate ParentOU → Subscriber
  2. For each subscriber: scan SubscriberOffers for ParameterInfo[TR_CONTRACT_NUMBER]
  3. If found and no successful response yet: build OPCDB_GET_PROPO_MAPPING event with MSISDN + OfferName (proposition)
  4. Send; increment RequestCount; log audit
  5. Set activity status "1"; persist
