Request_OPCDB_GET_PP_MAPPING

Queries OPCDB for price plan mapping by MSISDN and SharePlan main price plan — dedicated OPCDB system (not CCBS)

Priority: 5 ForwardChain: true Target: OPCDB Event: OPCDB_GET_PP_MAPPING Scope: ParentOU only Schema: PricePlanMapping.xsd
§1 — Overview & Purpose
OPCDB_GET_PP_MAPPING queries the OPCDB (Operations/Price Catalog DB) system to retrieve the price plan mapping for a subscriber based on their MSISDN and their SharePlan main subscriber's current price plan (SHAREPLAN_MAIN_PP). This is a distinct system from CCBS — it uses a dedicated OPCDB_GET_PP_MAPPING event and the PricePlanMapping.xsd schema namespace.
Used in: MNP_SHARE_PLAN flow — step executed after CCBS_GET_SHAREPLAN_MAIN_SUBS_PP to map the current PP to the new SharePlan price plan.
