Request_CCBS_SEARCH_SHAREPLAN_CHILD_SUB_ID

Searches CCBS for SharePlan child subscriber CCBS ID by MSISDN — uses IntraActivitySequencing; iterates ParentOU subscribers (the MNP source/child subs)

Priority: 5Target: CCBS Event: CCBS_SEARCH_SUBSCRIBER_BY_RESOURCE Scope: ParentOU onlyFan-in: IntraActivitySequencing
§1 — Overview & Purpose
CCBS_SEARCH_SHAREPLAN_CHILD_SUB_ID finds the CCBS subscriber ID for each SharePlan child (MNP subscriber). Despite the name "CHILD", it iterates ParentOU subscribers — in the MNP_SHARE_PLAN flow, these are the subscribers being ported in that will become SharePlan children. Uses IntraActivitySequencing for sequential processing. Reuses CCBS_SEARCH_SUBSCRIBER_BY_RESOURCE event with the subscriber's own MSISDN as parameterValue.
⚠ Name vs. iteration scope: The rule name says "CHILD_SUB_ID" but iterates ParentOU subscribers. In MNP context, ParentOU subscribers are the MNP source accounts that become SharePlan child subscribers post-activation.
