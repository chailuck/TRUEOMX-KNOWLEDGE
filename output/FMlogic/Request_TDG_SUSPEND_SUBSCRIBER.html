Request_TDG_SUSPEND_SUBSCRIBER

TIBCO BusinessEvents FM — TRUE Digital (TDG) Suspend Subscriber per-material-info loop
Rule: Rules.OMConsumers.OMXFM.Request.Request_TDG_SUSPEND_SUBSCRIBER Priority: 5 forwardChain: true Author: CHAYATORN P. Backend: TDG (TRUE Digital) Generated: 2026-09-16
§1 — Overview & Purpose

Fires when ActivityID == "TDG_SUSPEND_SUBSCRIBER". Unlike most subscriber FMs, this one iterates over MaterialInfo.Material entries (IoT/device materials) rather than subscribers directly. For each material, it sends a TDG_SUSPEND_SUBSCRIBER JMS event to the TRUE Digital back-end with the material's serial number and the associated contract offer name.

PreExecCheck gate: Subscriber must have TR_SPECIAL_OFFER_IND=IOTBU, meaning only IoT Business Unit subscribers reach this step.

Reason mapping: Channel=CCBS → reason "C" (Collection); otherwise → reason "R" (Regular).

propositioncode: Fetched from subscriber's SubscriberOffers/RelatedOffersArray where ServiceType=85 AND SocProperties contains TR_CONTRACT_IND=Y, selecting OfferName.

§5 — Execution Flow
  1. Get subscriber XML via GetXMLForSubscriberMaterialInfo
  2. Apply PreExecCheck: TR_SPECIAL_OFFER_IND=IOTBU
  3. Loop over MaterialInfo.Material[m]
  4.   Compute pmatchRefId = pSubRefId + ":" + material.MatCode
  5.   Skip if existing completed response for this refId
  6.   Resolve propositioncode from SubscriberOffers/RelatedOffersArray (ServiceType=85 + TR_CONTRACT_IND=Y)
  7.   Determine reason: Channel=CCBS → "C", else "R"
  8.   Fire TDG_SUSPEND_SUBSCRIBER event: serial=MatSerial, id=MSISDN, propositioncode, reason
  9.   ActionRequestEvent; increment RequestCount
  10. On any dispatch → SendFirstRequestEvent; status "1"; DB persist
  11. On all skip → SkipActivity("4")
