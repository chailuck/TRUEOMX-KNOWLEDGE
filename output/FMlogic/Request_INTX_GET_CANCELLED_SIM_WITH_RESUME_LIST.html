Request_INTX_GET_CANCELLED_SIM_WITH_RESUME_LIST

Retrieve cancelled SIM list eligible for resume (MultiSIM eSIM resume scenarios) from INTX; populates MIIMEI from eSIM resource data
Rule Priority: 5 ForwardChain: true Backend: INTX Pattern: Fire-and-Forget Author: SathidP-PC
§1 — Overview & Purpose

This rule fires when the process reaches INTX_GET_CANCELLED_SIM_WITH_RESUME_LIST. It sends a GetCancelledSIMWithResumeListReq to INTX for each active subscriber by MSISDN. The pattern is fire-and-forget: sendEventImmediate + RequestCount++. Guard: skips subscribers with blank MSISDN or those that already have MultiSIMInfo set. The response handler populates MIIMEI ResourceInfo from the eSIM resource list when the subscriber has an MSRES activity reason and the response contains eSimResourceOfferInfoList data matching by EID. Fan-in: count("000" ResponseCodes) == RequestCount.
