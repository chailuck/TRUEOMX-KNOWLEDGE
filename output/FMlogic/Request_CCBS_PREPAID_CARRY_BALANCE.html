Request_CCBS_PREPAID_CARRY_BALANCE

Carries prepaid credit balance to postpaid — adds carry-balance SOC to subscriber via CCBS UpdateSubscriber, skipping ATB2/IOU/L2 subscriber types.
Activity: CCBS_PREPAID_CARRY_BALANCE Backend: CCBS Pattern: IntraActivitySequencing Scope: Subscriber Generated: 2026-09-23
§1 — Overview & Purpose

Transfers a prepaid subscriber's main credit balance to a carry-balance SOC on their new postpaid account. Called during PREPAID_TO_POSTPAID conversion. The rule iterates all ParentOU and ChildOU subscribers, skips ATB2 (convergence), IOU, and L2 (price plan) subscriber types, reads MAIN_CREDIT from subscriber ExtendedInfo, caps it at a global CAP_MAX value, and adds the carry-balance offer via the CCBS UpdateSubscriber API.

The activity parameter format is socName:socCode (e.g., CARRYS01:11213612).

§5 — Execution Flow
  1. Parse activity parameter socName:socCode via String.split(param, ":")
  2. If resubmit: call PurgePendingRequestsBeforeResubmit
  3. Iterate ParentOU[i].Subscriber[j]: evaluate PreExecCheck via GetXMLForSubscriber
  4. For each passing subscriber: check ATB2/IOU/L2 skip conditions → skip if any match
  5. Read MAIN_CREDIT from subscriber ExtendedInfo, format to 2 decimal places
  6. If MAIN_CREDIT <= 0 → skip
  7. Read CAP_MAX from global variable; cap credit if exceeded
  8. Read USER_TEXT from global variable; substitute ${main_credit1} / ${main_credit2}
  9. If no successful prior response: fire CCBS_UPDATE_SUBSCRIBER event via IntraActivitySequencing
  10. If offer not already in subscriber: create SubscriberOffers instance and append
  11. Repeat steps 3–10 for ChildOU[m].Subscriber[j] (uses GetXMLForSubscriberInChildOU)
  12. After loop: if not skipped → SendFirstRequestEvent + set IN_PROGRESS; else → SkipActivity("4")
§7 — Subscriber Skip Logic (ATB2 / IOU / L2)
TypeXPath ConditionAction
ATB2not(exists($subs/ExtendedInfo[Name='CDB_CONVERGENCE'])) or substring(CDB_CONVERGENCE/Value,1,1) != '0'Skip subscriber (continue)
IOUnot(exists($subs/ExtendedInfo[Name='CDB_VAS'])) or substring(CDB_VAS/Value,17,1) = '1'Skip subscriber (continue)
L2not(exists(PRICEPLAN_CCP)) or (starts-with(PRICEPLAN_CCP/Value,'R') and contains(PRICEPLAN_CCP/Value,'DL'))Skip subscriber (continue)

All three conditions are checked with OR — if any matches, the subscriber is skipped.
