Request_SMS3CJ_GET_TEMPLATE_PREPAID_SUSPEND

Priority 5 forwardChain: true Target: 3CJ SMS Template Service Author: TIT_CP-CHAYAT2 Generated: 2026-09-15
§1 Overview & Purpose

This FM fetches the localized SMS notification template for the PREPAID_SUSPEND order flow from the 3CJ SMS template service. For each subscriber in the ParentOU hierarchy, it determines the subscriber's language preference and requests the corresponding SMS template from the downstream service. The retrieved template content is written back to the subscriber's ExtendedInfo collection as SMS_MSG, making it available for the subsequent OMX_SEND_SMS3CJ FM.

The activity is conditional — it only executes when the order channel is DWH_SIMBOX (PreExecCheck gate). If no template is retrieved for any subscriber, the activity is skipped (status "4").

§6 Rule Action (THEN) — Logic Detail

Outer try/catch wraps the entire body. On exception: HandleActivityException(orderRequest, orderCurrentActivity, ae, "")

Resubmit detection: isActResub = (orderCurrentActivity.RequestCount > 0 && orderRequest.IsOrderResubmitted)

PreExecCheck evaluation: if nextAct.PreExecCheck is non-empty, build XML slice via GetXMLForSubscriber(orderRequest, refId) and evaluate: XPath.execute("/(" + chkXPath + ")", sXML, ns). In the PREPAID_SUSPEND flow the gate is: /ns0:OrderRequest/OrderData/Channel/text()="DWH_SIMBOX"

IsSkipped flag: starts true; flipped to false after first successful send. Drives final status decision.

§18 Full Source Code
rule Rules.OMConsumers.OMXFM.Request.Request_SMS3CJ_GET_TEMPLATE_PREPAID_SUSPEND {
  attribute { priority = 5; forwardChain = true; }
  declare {
    Concepts.OrderRequest.OrderRequest orderRequest;
    Concepts.OM.ProcessConfig.Activity orderCurrentActivity;
  }
  when {
    orderCurrentActivity@extId == orderRequest.ProcessFlow.NextActivityName;
    orderCurrentActivity.ActivityID == "SMS3CJ_GET_TEMPLATE_PREPAID_SUSPEND";
    orderRequest.ProcessFlow.NextActivityID == "SMS3CJ_GET_TEMPLATE_PREPAID_SUSPEND";
    orderCurrentActivity.Status == "WAITING";
  }
  then {
    try {
      boolean isActResub = (orderCurrentActivity.RequestCount > 0 && orderRequest.IsOrderResubmitted);
      Concepts.OM.ProcessConfig.Activity nextAct = Instance.getByExtIdByUri(...);
      boolean isSkipped = true;
      long pid = System.nanoTime();

      for(int iPOU = 0; iPOU < orderRequest.OrderData.Customer.ParentOU@length; iPOU++) {
        for(int subs = 0; subs < pOu.Subscriber@length; subs++) {
          // ... resubmit guard ...
          // ... PreExecCheck gate via GetXMLForSubscriber + XPath.execute ...
          if(chkRes.equals("true")) {
            String language = subscriber.SubscriberGeneralInfo.Language;
            /* Build OMX_GET_3CJ_SMS_TEMPLATE request event via XSLT — see §9.8 */
            /* Payload: ns:OMX_Sms3CJTemplateRequest { languageCode, orderType(conditional) } */
            Event.Ext.sendEventImmediate(reqEvent);
            if(!isActResub) orderCurrentActivity.RequestCount++;
            /* Send audit Logger event — see §11 */
            isSkipped = false;
          }
        }
      }

      if(!isSkipped) {
        orderCurrentActivity.Status = RuleFunctions.Helpers.GetActivityStatusString("1", false);
        RuleFunctions.Helpers.SendDataToDB(orderRequest);
      } else {
        RuleFunctions.Helpers.SkipActivity(orderRequest, orderCurrentActivity, "4");
      }
    } catch(Exception ae) {
      RuleFunctions.Helpers.HandleActivityException(orderRequest, orderCurrentActivity, ae, "");
    }
  }
}
§19 Response Message Rule

§19.1 Overview

Response rulefunction: Response_SMS3CJ_GET_TEMPLATE_PREPAID_SUSPEND. Parses the 3CJ template service reply, extracts all templateContent values, concatenates them as the SMS message, and writes the result back to subscriber.ExtendedInfo[Name='SMS_MSG']. Also drives fan-in completion logic.

Additional post-processing: Loops over ParentOU.Subscriber, finds the matching RefId subscriber, reads all xsd2:omxnNotiTemplate[i]/xsd2:templateContent values from the response payload, concatenates them, and writes a new SubscriberExtendedInfo with Name=SMS_MSG, Value=smsContent.

§19.4 Response Completion Logic

Success XPath: count($currActivity/Response[tib:right(tib:trim(ResponseCode), 3) = "000"])

Fan-in condition: currActivity.RequestCount == successResponseCount

Returns "true" when all sent requests have received "000" responses — signals all parallel calls complete; returns "false" otherwise. Exception returns "false".
