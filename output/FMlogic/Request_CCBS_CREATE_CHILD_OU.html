Request_CCBS_CREATE_CHILD_OU

CCBS — Create ChildOU Under ParentOU and Retrieve CCBS-assigned OUId
Backend: CCBS Pattern: assertEvent + IntraActivitySequencing (per ChildOU) Priority: 5 Author: sakarin-pc Generated: 2026-09-21
§1 — Overview & Purpose

CCBS_CREATE_CHILD_OU creates Child Organisational Units under existing ParentOUs in CCBS. The key difference from CCBS_CREATE_PARENT_OU is the addition of ns:chArcInfo/ns:parentId (POU.OUId) which establishes the parent-child relationship in the CCBS hierarchy.

Loops ParentOU → ChildOU (two nested loops). Uses the same event type CCBS_CREATE_OU as CCBS_CREATE_PARENT_OU. The shared response handler matches by ChildOU.RefId and writes back ChildOU.OUId.
