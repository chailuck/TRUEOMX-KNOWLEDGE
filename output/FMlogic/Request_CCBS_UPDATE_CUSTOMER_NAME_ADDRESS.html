Request_CCBS_UPDATE_CUSTOMER_NAME_ADDRESS

CCBS — Update Customer Name & Address (3-variant: CORP / INDY / Default)

Priority: 5 forwardChain: true Backend: CCBS Pattern: IntraActivitySequencing NameType: CORP(66) / INDY(73) / Default(69) Generated: 2026-09-23
§1 — Overview & Purpose

Updates customer name and address information in CCBS. A 3-way xsl:choose on NameType determines which set of fields is submitted:

  • CORP (nameType=66): 8 core name elements + extended corporate block
  • INDY (nameType=73): 10 core name elements + extended individual block
  • Default (nameType=69): element2=PrefContactNumber only + extended block

Uses IntraActivitySequencing (ActionRequestEvent + SendFirstRequestEvent) — one request per customer. ActionResponseEvent in the response handler is active (not commented out).

💡 LogicalDate: Mapped to both enclosedClientInfo.logicalDate and ActivityDateInfo.activityDate.
