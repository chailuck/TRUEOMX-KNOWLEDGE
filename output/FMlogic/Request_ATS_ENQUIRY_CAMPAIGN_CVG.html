Request_ATS_ENQUIRY_CAMPAIGN_CVG

TIBCO BusinessEvents FM — ATS Enquiry Campaign (Convergence) + TVS_NO extraction side-effect
Rule: Rules.OMConsumers.OMXFM.Request.Request_ATS_ENQUIRY_CAMPAIGN_CVG Priority: 5 forwardChain: true No author Backend: ATS Generated: 2026-09-16
§1 — Overview & Purpose

Fires when ActivityID == "ATS_ENQUIRY_CAMPAIGN_CVG". Dual-loop per subscriber. Sends an ATS_ENQUIRY_CAMPAIGN JMS event for each subscriber to query ATS for active campaign data (product type TMV, accessNumber=MSISDN).

⚠ Important Side-Effect in Response Handler: The response rulefunction (Response_ATS_ENQUIRY_CAMPAIGN_CVG) does more than just fan-in — it parses the campaign response for campaign code "ATB8V2" with status ACTIVE or SUSPEND, then extracts productList[productType=TVS]/productId and writes it as TVS_NO ExtendedInfo on the matching subscriber. This TVS_NO is subsequently used by ICC_TVS_SUBMIT_ORDER when REASON=TFULL.

FUNCTION parameter: Read from GetActivityParameterValueFromKey("FUNCTION"). If absent/blank, defaults to "ALL".

§5 — Execution Flow
  1. Read FUNCTION param via GetActivityParameterValueFromKey (default "ALL")
  2. Outer loop: ParentOU[i]; inner loop: Subscriber[j]
  3.   Apply PreExecCheck per subscriber
  4.   Fire ATS_ENQUIRY_CAMPAIGN event: requestName="EnquiryCampaign", function param, activeFlag="Y", productType="TMV", accessNumber=MSISDN
  5.   ActionRequestEvent; send audit log
  6. Repeat for ChildOU.Subscriber paths
  7. On any dispatch → status "1"; DB persist
  8. On all skip → SkipActivity("4")

§19 — Response Message Rule
§19.1 Overview

Response_ATS_ENQUIRY_CAMPAIGN_CVG maps the ATS response into ResponseBase and performs an important TVS_NO extraction side-effect before fan-in.


§19.2 TVS_NO Extraction Algorithm
  1. Parse campaignInfo array in ATS response
  2. Find first entry where campaignCode = "ATB8V2"
  3. Check status == "ACTIVE" or "SUSPEND"
  4. Within that entry, find productList[productType="TVS"]
  5. Extract productId → tvsNo
  6. Find matching subscriber (by MSISDN/RefId) in both POU and COU
  7. Write TVS_NO to subscriber's ExtendedInfo array in Working Memory

§19.3 ResponseBase Construction
  • ResponseBase
    • extId←OMXUtils.generateTrackingID()Always
    • ResponseCode←$eventResponse/ResponseCodeConditional
    • ResponseMessage←$eventResponse/ResponseMsgConditional
    • CompletionStatus←$eventResponse/CompletionStatusConditional
    • ReferenceId←$eventResponse/RefIDConditional

§19.4 Fan-in Completion

Classic count: count($currActivity/Response[tib:right(tib:trim(ResponseCode), 3) = "000"]) == currActivity.RequestCount
