§1 — Overview & Purpose

Fires when ActivityID == "CCBS_APPLY_COLL_ACTIVITIES". Loops over all ParentOU and ChildOU subscribers, applies a PreExecCheck per subscriber, and fires a CCBS_APPLY_COLL_ACTIVITIES JMS event for each qualifying subscriber. The payload varies based on the serviceType parameter (from Parameter[0]), selecting the appropriate collection action code and SOC add/remove operation.

In FULL_SUSPEND context: serviceType=FULL_SUSPEND → collectionAct=83, removes SOC 50412. This is the CCBS-channel collection suspension path (triggered only when Channel="CCBS").
