Request_OMX_SYNCE_IDENTIFICATION

Syncs customer identification data and writes CHANGE_IDENTIFICATION ExtendedInfo flag

Activity: OMX_SYNCE_IDENTIFICATION Backend: OMX Internal No Outbound Call Author: usuf Generated: 2026-09-23
§1 — Overview & Purpose

A local computation rule with no outbound ESB/JMS call. Performs two tasks:

  1. Identification sync: Copies CustomerGeneralInfo.Identification and CustomerGeneralInfo.IdentificationType into CustomerName.Identification / CustomerName.IdentificationType (when both objects exist).
  2. Change-detection flag: Creates a CustomerExtendedInfo with Name="CHANGE_IDENTIFICATION". Sets value to "Y" if the customer's current Identification differs from the old one (ExtendedInfo[OLD_IDENTIFICATION]); otherwise value stays "N".

The CHANGE_IDENTIFICATION=Y flag gates both downstream MCS steps: MCS_GET_PACKCODE and MCS_CANCEL_AFTER_SALE — they only execute when identification has changed.

§5 — Execution Flow
  1. Identification sync (conditional): If CustomerGeneralInfo != null AND CustomerName != null:
    • Copy CustomerGeneralInfo.Identification → CustomerName.Identification
    • Copy CustomerGeneralInfo.IdentificationType → CustomerName.IdentificationType
  2. Create CustomerExtendedInfo instance with Name="CHANGE_IDENTIFICATION", Value="N" (default)
  3. Read OLD_IDENTIFICATION from Customer.ExtendedInfo via XPath
  4. Change-detection (conditional): If CustomerGeneralInfo != null AND Identification is not blank AND Identification != OLD_IDENTIFICATION: set Value = "Y"
  5. Append cusExtInf to Customer.ExtendedInfo array
  6. Call NextActivity to advance the process
  7. Fire audit log event
§8 — System & Integration Dependencies
No outbound backend call. This rule performs purely in-memory operations on the order request concept.

§18 — Full Source Code
rule Rules.OMConsumers.OMXFM.Request.Request_OMX_SYNCE_IDENTIFICATION {
    attribute { priority = 5; forwardChain = true; }
    declare {
        Concepts.OrderRequest.OrderRequest orderRequest;
        Concepts.OM.ProcessConfig.Activity orderCurrentActivity;
    }
    when {
        orderCurrentActivity@extId == orderRequest.ProcessFlow.NextActivityName;
        orderCurrentActivity.ActivityID == "OMX_SYNCE_IDENTIFICATION";
        orderRequest.ProcessFlow.NextActivityID == "OMX_SYNCE_IDENTIFICATION";
        orderCurrentActivity.Status == "WAITING";
    }
    then {
        try {
            if (orderRequest.OrderData.Customer.CustomerGeneralInfo != null
                && orderRequest.OrderData.Customer.CustomerName != null) {
                orderRequest.OrderData.Customer.CustomerName.Identification =
                    orderRequest.OrderData.Customer.CustomerGeneralInfo.Identification;
                orderRequest.OrderData.Customer.CustomerName.IdentificationType =
                    orderRequest.OrderData.Customer.CustomerGeneralInfo.IdentificationType;
            }

            /* Instance.createInstance(CustomerExtendedInfo XSLT — see §10) */
            /* Name="CHANGE_IDENTIFICATION", Value="N" by default */

            String oldIdentification = XPath.evalAsString("... $orderRequest/OrderData/Customer/ExtendedInfo[Name='OLD_IDENTIFICATION']/Value ...");

            if (orderRequest.OrderData.Customer.CustomerGeneralInfo != null
                && !IsBlankOrStringNull(orderRequest.OrderData.Customer.CustomerGeneralInfo.Identification)
                && !String.equals(orderRequest.OrderData.Customer.CustomerGeneralInfo.Identification, oldIdentification)) {
                cusExtInf.Value = "Y";
            }

            orderRequest.OrderData.Customer.ExtendedInfo[...] = cusExtInf;
            NextActivity(orderRequest, orderCurrentActivity);
            /* fire Logger audit event — see §11 */

        } catch (Exception ae) {
            HandleActivityException(orderRequest, orderCurrentActivity, ae, "");
        }
    }
}
