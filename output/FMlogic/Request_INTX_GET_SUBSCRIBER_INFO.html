Request_INTX_GET_SUBSCRIBER_INFO

Backend: INTX (Subscriber WS) Pattern: IntraActivitySequencing Author: awalia-t420 Generated: 2026-09-23
§1 — Overview & Purpose

Retrieves detailed subscriber information (initial activation date, minimum activation date) from the INTX subscriber web service. Called for every subscriber across POU and ChildOU. The response populates SubscriberGeneralInfo.InitActDate and l9TmvActDate (minimum of InitActDate and MinActivationDate) on the subscriber concept in working memory. For backdate order types (126, 127, 129, 15, 16), also writes an OLD_BAN_DATE ExtendedInfo record. Credentials are gated by the IsEnableUserPass global variable.

In the context of MOVE_SUBSCRIBER_NO_PROVISIONING (step 21), this is called with Parameter = SOURCE to retrieve source subscriber details before the move.

§5 — Execution Flow
  1. Purge pending requests if resubmit
  2. Iterate POU[i] → Subscriber[j]; evaluate PreExecCheck; skip if already responded
  3. Build GetSubscriberInfoReq with correlatedId = OMXTrackingId, subscriberNo = SubscriberId
  4. For POU variant: subscriberNo is unconditional; for ChildOU: guarded by xsl:if test="SubscriberId"
  5. Optionally include UserName/PassWord (gated by IsEnableUserPass)
  6. Event.assertEvent(reqEvent); IntraActivitySequencing.ActionRequestEvent(reqEvent, currActivity)
  7. Repeat for ChildOU[k] → Subscriber[j]
  8. IntraActivitySequencing.SendFirstRequestEvent(currActivity) → IN_PROGRESS

§19 — Response Message Rule

§19.1 Overview

Rich post-processing response handler. Creates INT_GetActivateDate concept, looks up the subscriber by RefID from working memory, creates/updates SubscriberGeneralInfo, writes activation dates, and (for backdate orders) adds OLD_BAN_DATE ExtendedInfo.

§19.3 Post-processing Logic

  1. Lookup subscriber: SUB:{OMXTrackingId}:{eventResponse.RefID} → if null try CSUB:...
  2. Get/create SubscriberGeneralInfo at extId SUBGI:{trackingId}:{subscriber.RefId}
  3. If initActDate is non-empty: parse and set subsGenInfo.InitActDate
  4. If minActivationDate is non-empty: set l9TmvActDate = minActivationDate; else set l9TmvActDate = initActDate
  5. Link: subscriber.SubscriberGeneralInfo = subsGenInfo
  6. For backdate OrderTypes (126/127/129/15/16): if OLD_BAN_DATE ExtendedInfo absent → create it with value = InitActDate

§19.4 Fan-in Completion

IntraActivitySequencing.ActionResponseEvent(currActivity)
→ returns true when all pending requests have received responses
