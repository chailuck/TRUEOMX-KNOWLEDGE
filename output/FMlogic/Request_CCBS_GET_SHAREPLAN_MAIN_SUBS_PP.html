Request_CCBS_GET_SHAREPLAN_MAIN_SUBS_PP

Retrieves SharePlan main subscriber price plan info from CCBS — anomalous SubscriberId-based response tracking

Priority: 5 ForwardChain: true Target: CCBS Event: CCBS_GET_SUBS_INFO Scope: ParentOU only Fan-in: SubscriberId (anomaly)
§1 — Overview & Purpose
CCBS_GET_SHAREPLAN_MAIN_SUBS_PP queries CCBS for the price plan of the SharePlan main subscriber, identified by ExtendedInfo[SHAREPLAN_MAIN_ID]. Reuses the CCBS_GET_SUBS_INFO event. Used in MNP_SHARE_PLAN to determine the main subscriber's current PP before performing a price plan mapping lookup (OPCDB_GET_PP_MAPPING).
⚠ Anomalous response tracking: This FM uses SubscriberId (not RefId) for ReferenceId matching in the response fan-in. This differs from the standard pattern used by all other ParentOU-iterating FMs. The CCBS response carries SubscriberId as the correlation key.

§5 — Execution Flow
  1. Iterate ParentOU[i] → Subscriber[j]
  2. Check if response already received: match by SubscriberId (NOT RefId) + CompletionStatus==2
  3. Evaluate PreExecCheck per subscriber
  4. Get mainSubCcbsId from ExtendedInfo[SHAREPLAN_MAIN_ID]
  5. Build CCBS_GET_SUBS_INFO event with GetSubscriberInfoRequest.subscrNumber = mainSubCcbsId
  6. Send; increment RequestCount; log audit
  7. Set activity status "1"; persist
