Request_CCBS_SUSPEND_SUBS

TIBCO BusinessEvents FM — CCBS Suspend Subscriber per-subscriber dual-loop request
Rule: Rules.OMConsumers.OMXFM.Request.Request_CCBS_SUSPEND_SUBS Priority: 5 forwardChain: true Author: awalia-t420 Backend: CCBS Generated: 2026-09-16
§1 — Overview & Purpose

Fires when orderCurrentActivity.ActivityID == "CCBS_SUSPEND_SUBS" and status is WAITING. Loops over all ParentOU and ChildOU subscribers, applies the PreExecCheck XPath against each subscriber's XML, and fires an individual CCBS_SUSPEND_SUBS JMS event to the CCBS back-end for each qualifying subscriber. The request carries the subscriber number, an optional effective date, and an activity reason (defaulting to CREQ). Completion uses IntraActivitySequencing.ActionResponseEvent fan-in rather than a manual success-count XPath (the manual XPath block is commented out in the source).

§5 — Execution Flow
  1. Detect resubmit flag (isActResub)
  2. Load logicalDateRes (not used in payload for this FM but loaded)
  3. Outer loop: ParentOU[i]
  4.   Inner loop: Subscriber[j] → check already-completed response; apply PreExecCheck; fire CCBS event
  5.   Inner loop: ChildOU[k] → Subscriber[j] → same pattern via ChildOU XML helper
  6. If any request fired: SendFirstRequestEvent → status = "1" (WAITING_RESPONSE) → persist to DB
  7. If all skipped: SkipActivity with reason "4"
  8. Catch block → HandleActivityException
§6 — Rule Action (THEN)

Per-subscriber logic (both POU and COU paths):

  • Skip subscriber if a matching Response[ReferenceId==refId, CompletionStatus==2] already exists (resubmit idempotency)
  • Apply PreExecCheck via GetXMLForSubscriber / GetXMLForSubscriberInChildOU
  • If check passes: create CCBS_SUSPEND_SUBS event via XSLT, call ActionRequestEvent, send audit log
  • Set isSkipped = false

// Rule: Rules.OMConsumers.OMXFM.Request.Request_CCBS_SUSPEND_SUBS
rule Rules.OMConsumers.OMXFM.Request.Request_CCBS_SUSPEND_SUBS {
  attribute { priority = 5; forwardChain = true; }
  declare {
    Concepts.OrderRequest.OrderRequest orderRequest;
    Concepts.OM.ProcessConfig.Activity orderCurrentActivity;
  }
  when {
    orderCurrentActivity@extId == orderRequest.ProcessFlow.NextActivityName;
    orderCurrentActivity.ActivityID == "CCBS_SUSPEND_SUBS";
    orderRequest.ProcessFlow.NextActivityID == "CCBS_SUSPEND_SUBS";
    orderCurrentActivity.Status == "WAITING";
  }
  then {
    boolean isActResub = (orderCurrentActivity.RequestCount > 0 && orderRequest.IsOrderResubmitted);
    try {
      // ... (see §9.8 for XSLT payload detail)
      // Dual-loop: ParentOU.Subscriber + ChildOU.Subscriber
      // Per-subscriber: PreExecCheck → create CCBS_SUSPEND_SUBS event → ActionRequestEvent → audit log
      // On any dispatch: SendFirstRequestEvent; Status="1"; SendDataToDB
      // On all skip: SkipActivity("4")
    } catch (Exception ae) {
      RuleFunctions.Helpers.HandleActivityException(orderRequest, orderCurrentActivity, ae, "");
    }
  }
}

Response rulefunction Response_CCBS_SUSPEND_SUBS: receives CCBS_SUSPEND_SUBS response event, builds CCBSSuspendSubsRes concept, appends to currActivity.Response[], sends audit log, and calls IntraActivitySequencing.ActionResponseEvent for fan-in.
