Request_OMX_SEND_SMS3CJ

Priority 5 forwardChain: true Target: 3CJ SMS Gateway Author: TIT_CP-CHAYAT2 Generated: 2026-09-15
§1 Overview & Purpose

This FM sends an SMS notification to each prepaid subscriber via the 3CJ SMS gateway. It is conditional — it only executes if subscribers have a non-empty SMS_MSG ExtendedInfo entry (populated by the preceding SMS3CJ_GET_TEMPLATE_PREPAID_SUSPEND step). For each qualifying subscriber, it formats the mobile number to international format (+66), retrieves the current Bangkok time, constructs a WhatupSMS schema payload, and dispatches the SMS through the OMX_SEND_SMS3CJ ESB event.

There is a commented-out WHATUP_SEND_SMS variant in the source; the active implementation uses the 3CJ gateway.

§5 Execution Flow Diagram
1Load nextAct; compute isActResub
2Loop over ParentOU[i].Subscriber[j]
3Resubmit guard: skip subscriber if Response with matching SubscriberId + CompletionStatus=2 exists
4PreExecCheck gate: evaluate count(//Subscriber//ExtendedInfo[Name='SMS_MSG' and Value != '']) > 0
5Extract sms_message via XPath on subscriber.ExtendedInfo[Name='SMS_MSG']/Value
6Format mobile_number: replace leading "0" with "66"
7Format createDate in Asia/Bangkok timezone: yyyy-MM-dd'T'HH:mm:ssZ
8Get basicAuthen from ExtendedInfo[Name='SMS_AUTHEN']/Value → prepend "Basic "
9Build OMX_SEND_SMS3CJ event via XSLT (WhatupSMS schema) and send
10Increment RequestCount (non-resubmit only)
11Send audit Logger event
12Post-loop: status "1" if any sent; SkipActivity("4") otherwise
§6 Rule Action (THEN) — Logic Detail

Resubmit detection: isActResub = (RequestCount > 0 && IsOrderResubmitted) — checked against Response by SubscriberId (not RefId).

PreExecCheck: evaluates nextAct.PreExecCheck against subscriber XML slice. In PREPAID_SUSPEND flow: count(//Subscriber//ExtendedInfo[Name/text()='SMS_MSG' and Value/text()!='']) > 0.

Mobile number formatting: if (startsWith(MSISDN,"0")) → replaceFirst("0","66").

Authentication: basicAuthen = "Basic " + ExtendedInfo[Name='SMS_AUTHEN']/Value (only prepended if non-blank).

Service-id logic: uses ExtendedInfo[Name='SMS_SERVICEID'] if present, else falls back to global variable OMX_OM/Services/OMX_SEND_SMS_3CJ/serviceid.

Originate omission rule: <ns:originate> is omitted when serviceid starts-with "72", "21", or "22".

§9.8 XSLT Stylesheet Source (Active Variant)

<!-- OMX_SEND_SMS3CJ Request XSLT (WhatupSMS schema) -->
<xsl:stylesheet xmlns:xsl="http://www.w3.org/1999/XSL/Transform"
  xmlns:ns="http://www.tibco.com/schemas/OMX-COMMON/_SharedResources/Schemas/ESB/Whatup/WhatupSMS.xsd"
  version="1.0">
  <xsl:param name="orderRequest"/>
  <xsl:param name="subscriber"/>
  <xsl:param name="basicAuthen"/>    <!-- "Basic " + SMS_AUTHEN ExtendedInfo -->
  <xsl:param name="globalVariables"/>
  <xsl:param name="mobile_number"/>   <!-- MSISDN with 0→66 prefix -->
  <xsl:param name="sms_message"/>    <!-- from ExtendedInfo[SMS_MSG] -->
  <xsl:param name="createDate"/>     <!-- Bangkok ISO timestamp -->
  <xsl:template match="/">
    <createEvent><event>
      <JMSPriority>$orderRequest/OrderPriority</JMSPriority>
      <JMSCorrelationID>$orderRequest/OrderData/OMXTrackingId</JMSCorrelationID>
      <OrderID>$orderRequest/OrderData/OrderID</OrderID>
      <!-- RefID: conditional on subscriber/SubscriberId -->
      <xsl:if test="$subscriber/SubscriberId">
        <RefID>$subscriber/SubscriberId</RefID>
      </xsl:if>
      <OrderType>$orderRequest/OrderData/OrderType</OrderType>
      <SMS_AUTHEN>$basicAuthen</SMS_AUTHEN>
      <payload><ns:message><ns:sms type="mt">
        <!-- service-id: use SMS_SERVICEID ExtendedInfo if present, else globalVar -->
        <ns:service-id>if count(SMS_SERVICEID)>0 then SMS_SERVICEID else globalVars/.../serviceid</ns:service-id>
        <!-- destination: conditional on mobile_number length -->
        <xsl:if test="string-length($mobile_number) > 0">
          <ns:destination><ns:address><ns:number type="international">$mobile_number</ns:number></ns:address></ns:destination>
        </xsl:if>
        <ns:source><ns:address>
          <ns:number type="abbreviated">globalVars/.../shortcodesms</ns:number>
          <!-- originate: omit if serviceid starts-with 72, 21, or 22 -->
          <xsl:if test="not(starts-with(serviceid,'72') or starts-with(serviceid,'21') or starts-with(serviceid,'22'))">
            <ns:originate type="international">globalVars/.../originate</ns:originate>
          </xsl:if>
          <ns:sender>globalVars/.../sender</ns:sender>
        </ns:address></ns:source>
        <ns:ud type="text" encoding="unicode">$sms_message</ns:ud>
        <ns:scts>$createDate</ns:scts>
        <ns:dro>true</ns:dro>
      </ns:sms></ns:message></payload>
    </event></createEvent>
  </xsl:template>
</xsl:stylesheet>

§18 Full Source Code
rule Rules.OMConsumers.OMXFM.Request.Request_OMX_SEND_SMS3CJ {
  attribute { priority = 5; forwardChain = true; }
  declare {
    Concepts.OrderRequest.OrderRequest orderRequest;
    Concepts.OM.ProcessConfig.Activity orderCurrentActivity;
  }
  when {
    orderCurrentActivity@extId == orderRequest.ProcessFlow.NextActivityName;
    orderCurrentActivity.ActivityID == "OMX_SEND_SMS3CJ";
    orderRequest.ProcessFlow.NextActivityID == "OMX_SEND_SMS3CJ";
    orderCurrentActivity.Status == "WAITING";
  }
  then {
    Concepts.OM.ProcessConfig.Activity nextAct = Instance.getByExtIdByUri(...);
    boolean isActResub = (orderCurrentActivity.RequestCount > 0 && orderRequest.IsOrderResubmitted);
    try {
      boolean isSkipped = true;
      for(...ParentOU[iPOU].Subscriber[subs]...) {
        // Resubmit guard: skip if Response[SubscriberId + CompletionStatus=2] exists
        // PreExecCheck gate: count(SMS_MSG non-empty) > 0
        if(chkRes.equals("true")) {
          String sms_message = XPath.evalAsString(/* ExtendedInfo[SMS_MSG]/Value */);
          String mobile_number = ... /* format 0→66 */;
          DateTime createDate = ... /* Bangkok TZ */;
          String basicAuthen = XPath.evalAsString(/* SMS_AUTHEN */);
          if(!IsBlankOrStringNull(basicAuthen)) basicAuthen = "Basic " + basicAuthen;
          /* Build OMX_SEND_SMS3CJ request event via XSLT — see §9.8 */
          /* Payload: WhatupSMS schema, MT, mobile_number, sms_message (unicode) */
          Event.Ext.sendEventImmediate(reqEvent);
          if(!isActResub) orderCurrentActivity.RequestCount++;
          /* Send audit Logger event — see §11 */
          isSkipped = false;
        }
      }
      if(!isSkipped) {
        orderCurrentActivity.Status = RuleFunctions.Helpers.GetActivityStatusString("1", false);
        RuleFunctions.Helpers.SendDataToDB(orderRequest);
      } else {
        RuleFunctions.Helpers.SkipActivity(orderRequest, orderCurrentActivity, "4");
      }
    } catch(Exception ae) {
      RuleFunctions.Helpers.HandleActivityException(orderRequest, orderCurrentActivity, ae, "");
    }
  }
}
