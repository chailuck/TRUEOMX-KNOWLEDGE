Request_ASRM_INVOKE_MSISDN

ASRM Unified Resource Activity — MSISDN Operations (LOCK / RESERVE / PREACTIVATE / ACTIVATE / PORT IN / PORT OUT)
Priority: 5 forwardChain: true Backend: ASRM Channel: OMXFMConnectionRequest Generated: 2026-07-23
§1 — Overview & Purpose

This rule fires when the order orchestration engine reaches an activity with ActivityID = ASRM_INVOKE_MSISDN and status WAITING. It sends a UnifiedResourceActivity request to ASRM (Amdocs Resource Manager 3G) for every eligible subscriber in the order — both at ParentOU and ChildOU levels.

The specific MSISDN operation is driven by the ACTIVITY parameter defined in the ProcessConfig, which can be one of: LOCK, RESERVE, PREACTIVATE, ACTIVATE, PORT IN, PORT OUT RELEASE, PORT IN REVERSE, PORT OUT REVERSE, ACTIVATED.

For PORT IN and PORT OUT RELEASE activities, zone codes stored as ASCII integers in the order are first decoded to text using OMXUtils.asciiCodeToText before being sent to ASRM. Subscribers that already have a SUCCESS response (CompletionStatus=2) for the current activity are skipped, enabling safe resubmission.

Each sent request increments orderCurrentActivity.RequestCount. The activity status transitions to IN_PROGRESS after dispatching. If all subscribers are skipped by the PreExecCheck, the activity is marked SKIPPED.

⚠ Two subscriber scopes: This rule handles both ParentOU subscribers (ParentOU[i]/Subscriber[j]) and ChildOU subscribers (ParentOU[i]/ChildOU[k]/Subscriber[j]) producing two XSLT variants that differ only in the XPath subscriber navigation path.

§5 — Execution Flow Diagram
1
Parameter Parsing — Iterate orderCurrentActivity.Parameter[] using XPath tib:tokenize($param, "=") to extract ACTIVITY key-value pair → activityValue
2
Zone Code Decode — If activityValue == "PORT IN" or "PORT OUT RELEASE": decode DonorZoneCode and RCPZoneCode via OMXUtils.asciiCodeToText(Number.intValue(code, 10))
3
Build operator name — operatorname = ActivityID + "_" + activityValue (used in audit log OPERATION_NAME)
4
ParentOU Loop — For each ParentOU[i] → Subscriber[j]:
  • Skip if Response[].ReferenceId == refId && CompletionStatus == 2 (already succeeded)
  • Run PreExecCheck via RuleFunctions.Helpers.GetXMLForSubscriber + XPath.execute
  • If passes: build & send ASRM_INVOKE_UNIFIED_RESOURCE_ACTIVITY event (ParentOU XSLT variant ①)
  • Send audit Logger event (if AllowWriteLog is true)
  • Increment orderCurrentActivity.RequestCount (if not resubmit)
5
ChildOU Loop — For each ParentOU[i] → ChildOU[k] → Subscriber[j]: same logic as step 4 using ChildOU XSLT variant ②
6
Status Update
  • If any request sent (!isSkipped) → Status = IN_PROGRESS, call SendDataToDB
  • If all skipped → RuleFunctions.Helpers.SkipActivity(orderRequest, orderCurrentActivity, "4") → Status = SKIPPED, advance to next activity
7
Exception Handling — catch(Exception ae) → RuleFunctions.Helpers.HandleActivityException → Status = ERROR, order status = FAILED, error logger fired
§6 — Rule Action (THEN) — Step-by-Step Logic

6.1 Initialization

// Resubmit guard — if order is being resubmitted, don't double-count RequestCount boolean isActResub = (orderCurrentActivity.RequestCount > 0 && orderRequest.IsOrderResubmitted); // Get next activity concept by extId for PreExecCheck evaluation Concepts.OM.ProcessConfig.Activity nextAct = Instance.getByExtIdByUri(orderRequest.ProcessFlow.NextActivityName, "/Concepts/OM/ProcessConfig/Activity"); int iPOULen = orderRequest.OrderData.Customer.ParentOU@length;

6.2 Parameter Parsing

for (int iParam=0; iParam<orderCurrentActivity.Parameter@length; iParam++) { String param = XPath.evalAsString("xpath://... $orderCurrentActivity/Parameter[(number($iParam)+1)]"); String paramKey = XPath.evalAsString("xpath://... tib:tokenize($param, \"=\")[1]"); String paramValue = XPath.evalAsString("xpath://... tib:tokenize($param, \"=\")[2]"); if(String.equals("ACTIVITY", paramKey)) activityValue = paramValue; }

6.3 Zone Code Decode (PORT IN / PORT OUT RELEASE only)

if(String.equals(activityValue, "PORT IN") || String.equals(activityValue, "PORT OUT RELEASE")) { if(!RuleFunctions.Helpers.BRMS.IsBlank(orderRequest.OrderData.MNPInfo.DonorZoneCode)) donorZoneText = OMXUtils.asciiCodeToText(Number.intValue(orderRequest.OrderData.MNPInfo.DonorZoneCode, 10)); if(!RuleFunctions.Helpers.BRMS.IsBlank(orderRequest.OrderData.MNPInfo.RCPZoneCode)) rcpZoneText = OMXUtils.asciiCodeToText(Number.intValue(orderRequest.OrderData.MNPInfo.RCPZoneCode, 10)); }

6.4 Per-Subscriber Dispatch (ParentOU)

for (int i=0; i<iPOULen; i++) { for(int j=0; j<iSubscriberLen; j++) { // 1. Skip check boolean reqSuccess = false; for(int iResp=0; iResp<orderCurrentActivity.Response@length; iResp++) if(refId matches && CompletionStatus==2) reqSuccess = true; if(!reqSuccess) { // 2. PreExecCheck String chkRes = "true"; if(String.length(nextAct.PreExecCheck) > 0) { String sXML = RuleFunctions.Helpers.GetXMLForSubscriber(orderRequest, refId); chkRes = XPath.execute("/("+nextAct.PreExecCheck+")", sXML, ns); } if(String.equals(chkRes, "true")) { // 3. Send ASRM request event (ParentOU XSLT variant) Events.OMConsumers.OMXFM.Request.ASRM_INVOKE_UNIFIED_RESOURCE_ACTIVITY reqEvent = Event.createEvent("xslt://{{/Events/OMConsumers/OMXFM/Request/ASRM_INVOKE_UNIFIED_RESOURCE_ACTIVITY}}" /* see §9.8 Variant ① for full XSLT — builds UnifiedResourceActivityInfo for ParentOU[i]/Subscriber[j]/MSISDN */); Event.Ext.sendEventImmediate(reqEvent); // 4. §7 — Data Extraction

Parameter Parsing — tib:tokenize

Parameters in orderCurrentActivity.Parameter[] are stored as KEY=VALUE strings. The rule uses tib:tokenize($param, "=") to split on =:

Token IndexExtracted ValueVariable
[1]Key (e.g., ACTIVITY)paramKey
[2]Value (e.g., LOCK, RESERVE, etc.)paramValue → activityValue

Zone Code ASCII Conversion

DonorZoneCode and RCPZoneCode are stored as decimal ASCII values. Number.intValue(code, 10) converts string to integer, then OMXUtils.asciiCodeToText(int) produces the human-readable zone text sent to ASRM.

§13 — Exception / Error Handling

The entire THEN block is wrapped in try { ... } catch(Exception ae) { ... }.

RuleFunctions.Helpers.HandleActivityException(orderRequest, orderCurrentActivity, ae, "") performs:

  • Builds error response code: ComponentName + ServiceCode + OpCode + HighSeverity("03") + GenericError("999")
  • Sets orderCurrentActivity.Status = ERROR
  • Sets orderRequest.OrderStatus = FAILED
  • Fires error Logger event to /Channels/LogConnection/ErrorLog with ERROR_CODE, ERROR_MSG, ERROR_STACKTRACE
  • If orderCurrentActivity.ExceptionActivity is configured, advances to that exception-handling activity
  • Calls SendDataToDB to persist failure

§17 — Migration Notes & Recommendations

Functional Requirements

  • R1 — Must support all 8 MSISDN activity types: LOCK, RESERVE, PREACTIVATE, ACTIVATE, PORT IN, PORT OUT RELEASE, PORT IN REVERSE, PORT OUT REVERSE, ACTIVATED.
  • R2 — Must iterate over both ParentOU and ChildOU subscriber hierarchies independently.
  • R3 — Must evaluate per-subscriber PreExecCheck XPath before dispatching to avoid unnecessary ASRM calls.
  • R4 — Must skip subscribers with existing SUCCESS responses (idempotent resubmission safety).
  • R5 — Zone codes (DonorZone, RCPZone) must be decoded from ASCII decimal before sending to ASRM.
  • R6 — PORT IN attribute population depends on OrderType; migrate the full condition matrix in §8.1.
  • R7 — RequestCount must only be incremented on fresh requests (not resubmit flag).

§19 — Response Message Rule

§19.1 — Overview

Rule function RuleFunctions.OrderResponse.Response_ASRM_INVOKE_MSISDN is invoked when ASRM returns a ASRM_INVOKE_UNIFIED_RESOURCE_ACTIVITY response event. It parses the response, appends it to the activity's Response array, logs the audit trail, then evaluates whether all parallel requests have succeeded (fan-in completion check).

// Count responses with ResponseCode ending in "000" (success) int successResponseCount = XPath.evalAsInt( "count($currActivity/Response[tib:right(tib:trim(ResponseCode), 3) = \"000\"])"); // Fan-in: all dispatched requests must have succeeded if(currActivity.RequestCount == successResponseCount) return "true"; // all parallel ASRM calls succeeded → advance to next activity else return "false"; // still waiting for more responses
