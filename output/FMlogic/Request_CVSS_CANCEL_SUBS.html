Request_CVSS_CANCEL_SUBS

Backend: CVSS (Subscriber Cancellation) Pattern: IntraActivitySequencing Author: awalia-t420 Generated: 2026-09-23
§1 — Overview & Purpose

Cancels subscriber(s) in the CVSS system. Iterates at Account level (not POU/ChildOU subscriber level), using GetXMLForAccount for PreExecCheck evaluation. Contains complex OrderType-specific logic: for OrderType=11002 (shareplan), it handles parent/child subscriber relationships with SHAREPLAN_PARENT_TYPE counting; for other order types it applies standard cancel logic. The source field is derived from channel/order type (EOC → "EOC"; MNP with donor codes → "MNP_INT" or "MNP_EXT"; else → "CCBS"). No credentials are included.
